# 27MHz伸缩天线用于31MHz：仿真筛查

日期：2026-11-19。结论：存在调到31MHz的合理工程路径；没有验证截图中ABBREE商品的实际适配。暂不据此改变既定电路或追加购买332/392。

## 本次实际计算

使用项目已有NEC2求解器重新运行几何模型：均匀直径3mm、长度可调的钢杆，距地83cm，土壤介电常数13、电导率0.005S/m；名义回流结构为8根各50cm铜地线。源位于杆底端第一段。

首先以130cm杆在27MHz的NEC输入电抗反推出理想串联加载电感约3.336µH，再固定该电感，在31MHz逐步改变杆长并求输入电抗过零点。实际商品没有拆解，也没有已知的内部线圈、变压器、壳体、节间接触和馈线模型。未模拟加载线圈损耗和自容；不验证辐射效率、AM带宽或链路距离。

## 结果

| 检查项 | 结果 |
|---|---|
| 名义几何60段，8×50cm地线 | 约86cm时31MHz输入电抗过零 |
| 改40、80段进行网格核查 | 约87.2cm、85.1cm；还不宜把86cm当精确施工尺寸，也没有完成严格网格收敛 |
| 内部理想加载电感假设为名义的90% | 约98.9cm |
| 内部理想加载电感假设为名义的110% | 约75.6cm |
| 内部理想加载电感假设为名义的80% | 约114.8cm，超出项目约1m工作长度目标 |
| 内部理想加载电感假设为名义的120% | 约67.1cm |
| 同一名义加载电感，地线改成4×50cm | 约110.9cm，超过1m |
| 同一名义加载电感，地线改成4×25cm | 扫查50～130cm未找到输入电抗过零点 |

电感±10%/±20%为人为敏感性场景，不是该商品标注容差，不代表通过率或概率；改变电感后的场景也不再保证130cm时仍在27MHz谐振。地线变化是在固定加载电感下计算，体现安装条件影响，不是4根地线必然优劣的通用结论。

## 解释与下一步

如果实物确为主要由串联线圈加载的伸缩单极子，收短辐射杆可提高谐振频率，这条路线在名义模型中可行。实际回流路径、内部匹配和线圈损耗足以改变所需长度及输出，因此不能把“计算存在电抗过零点”升级为“实物已匹配、效率够、6m验收通过”。本项目也没有强制必须50Ω的课程指标；后续应结合现有驱动的电流/电压及实际接收结果判断。

到货后保持最终板地、供电线、天线底座和馈线安装状态，优先借VNA或阻抗分析仪测25～35MHz，逐步伸缩天线，记录31MHz复阻抗及低电抗点。频率跨度和长度变化均只用于低功率测量。若有1m限制，应在允许工作长度内寻找。拿到实测复阻抗后再决定是否加外部匹配以及332/392是否适用；不因本次筛查更换整套选型。
