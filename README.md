## 当前验证边界

截至 2026-10-29，S05 接收端完成首批独立仿真：BAT85 厂家模型检波、F1 滤波与 R1 接收候选（31 MHz 增益 51.49 倍）已跑通并全部台账化；但输入选频（全频峰值在约 1.60 MHz）、BAT85S 型号对应模型、基带输出级与无线实测均未完成，**整机灵敏度和 6 m 距离不成立**。S04 的独立 2N3904 振荡器标称假设模型通过末窗稳定性筛查，独立缓冲已开展带载探索；放大与隔离连接、晶体型号参数和整机电池端功耗尚未闭合。仿真结果不等于实物验收，详见各报告的条件和限制。

## 文件与复现

`simulation/` 保存工程、网表、脚本和测量摘要，`项目管理/` 保存计划与验证状态，`output/` 保存实验图册等交付物。

保留原有 Git 历史。按 `.gitignore`，大型原始波形（例如 `.raw`、`.gra`、`.npz`）、软件安装包及缓存不上传；部分证据仅保存在本机，摘要中留有路径或哈希。因此克隆本仓库不等于获得所有原始数据。运行脚本前需要安装相应软件并核对脚本中的本地路径；仓库不是开箱即用的软件包。
