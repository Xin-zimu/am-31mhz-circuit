## 当前验证边界

**2026-10-30 S04 当前状态同步（C3/C4）**：晶体振荡器、射随缓冲和共射增益级已级联并自主起振；C3 数值校正后的频率约30.99892 MHz，C4 的2 kΩ档为1.9995 Vpp，10 kΩ档为2.0863～2.1104 Vpp（随求解容差跨越2.1 V上限，待收敛确认）。H2为−18.94～−19.76 dBc，未达到−20 dBc内控目标。旧0.415 Vpp仅代表早期缓冲测试，不能再作为当前TP2输出或“仍缺约4倍增益”的依据。加载牵引D5-a、晶体型号参数、真实调制/发射级与电池端总功耗仍未闭合；未完成整机或实物验收。见[S04路线状态](simulation/v4_hardware/stage4_rf_oscillator/S04_RF_CARRIER/README.md)。

**2026-10-30 S05-10 实物实施前检查已完成（实测待执行）**：用户确定RX继续9 V，保留A+原Q1/Q2+G22；已确认示波器为DS2102E（100 MHz、内置50 Ω）；用户确认有信号发生器，型号与28～34 MHz正弦覆盖待查，“高阻/低阻”是发生器负载设置；低电容探头大概没有，现有探头型号待查。已整理独立LC规格清单、两条测量路线、制作/微调顺序和空白扫频记录。新增4个局部AC、0个瞬态，2752个历史阶段文件哈希不变。**纠正S05-09测量估算**：rf的1 kΩ是负载，不是源阻抗；原AC夹具额外接10 pF时G31变化+0.130 dB、带宽−16.7 kHz，不能沿用−6.81 dB补偿。10 pF直接接tank仍不适合定量验收。独立LC用953 Ω与总14 pF模拟Q1输入，探头/缓冲电容须计入总量；候选测试缓冲尚未完成器件/实物稳定性资格。**下一步仅确认器件仪器、制作可调可测的独立LC，不焊完整RX。** 未采购、未测硬件、未关闭Q31/S11/BAT85S/20 mV过载/启动/真实TX联调。见[S05-10操作清单](simulation/v4_hardware/stage5_receiver/S05_10_实物实施前检查与LC测量准备.md)。

**设备状态补充**：发生器负载菜单说明、50 Ω校验步骤及普通探头条件性方案见[现有仪器与阻抗设置](simulation/v4_hardware/stage5_receiver/S05_10_补充_现有仪器与阻抗设置.md)。尚未实测，原S05-10证据保留。

**S05-09已归档**：9 V保留决策已由用户确认；原报告及失败证据不覆盖。其中rf探头RC估算、抑制符号解释及Q31“手册下限”的表述以[S05-10接口校核与勘误](simulation/v4_hardware/stage5_receiver/s05_10_measurement_20261030/接口校核与勘误.md)为准；Q66@25 MHz不等于Q31保证，互感也不是唯一实物风险。

**2026-10-30 S05-08 真实可采购元件验证**：把 S05-07 的设计夹具换成带数据手册出处的器件模型（132-17L：Q≥66@25 MHz、SRF≥340 MHz；BFC280905003：2–18 pF、tanδ≤25×10⁻⁴@100 MHz），接回检波器/Q1/Q2/G22 复验整链。**邻近抑制成立**（19 组重调谐条件 −11.36～−13.71 dB）；**10 mV 档整链成立**（标称 5.109/5.092 Vpp，假设 Q31=66 下仍 4.938/4.922 Vpp）；**20 mV 仍过载**（50% 方波 8.66 Vpp、48.4% 贴轨）。**输入匹配未解决**：31 MHz 看入 119.86+j67.56 Ω、回波损耗 5.49 dB，调谐改变不了它；放开 CSEL 可到 20.08 dB 但带宽掉到 1.6479 MHz，未替换主网表。**最大实物风险是两只空芯线圈互感**：k=−0.03 带宽涨到 3.04 MHz、抑制掉到 −5.6 dB 且重调救不回；k=+0.03 增益腰斩到 10.64 V/V，**k 未换算成间距**。调谐范围核算：微调 5.84～14.97 / 5.67～11.12 pF，距端点 ≥3.0 pF。见 [S05-08](simulation/v4_hardware/stage5_receiver/S05_08_可采购元件与整链验证.md)。

**2026-10-30 S05-07 首批**：S05-06 已归档，按用户调整后的优先级转入 LC 实物化；新增38份局部AC与48组调谐角点计算，历史2014个S05文件哈希未变，未重跑两个未完成瞬态。独立标准值夹具（460 nH、假设Q50、15/11/2.4 pF）调谐后中心31.000 MHz、带宽1.919 MHz、两侧抑制12.59/11.80 dB；实际器件Q31、输入匹配和新元件版整链幅度仍待验。已给出132-17L少量备样与双微调清单；用户尚未采购、仅有示波器，实物扫频还需可用的RF激励源。见 [S05-07](simulation/v4_hardware/stage5_receiver/S05_07_LC实物化与调谐验证.md)及[S05-06增益单位勘误](simulation/v4_hardware/stage5_receiver/S05_06_勘误_增益单位.md)。不引入AGC，不回到B；20 mV动态范围在课程或实际链路范围明确后处理。

2026-10-30 新增（S05-06）：A 方案把 OPA197 基带增益由 11.2 提到 22（仅 RFB 102 kΩ→210 kΩ），**标称 10 mV / 50 Ω 下 10%/50% 方波恢复到 4.7770/4.7594 Vpp、20 kHz、占空比 10.70%/50.70%、无削顶**，邻近阻塞改善基本保留（单个 10 mV 干扰下检波基波仅降 0.30～0.51 dB）；29/33 MHz 的 1 dB 边界仍是 50～60 / 40～50 mV。**仍未通过**：①20 mV 输入在 G22 下削底（50% 方波低端 30.5 mV、48.33% 窗口贴近下轨），20 mV/10% 方波本轮没有有效数组、属未完成而非不合格；②电感 Q、容差与输入匹配未收敛 —— Q20→80 使增益 20.96→46.36 V/V（26.43→33.32 dB），L 同向 ±5% 不重调会把一侧抑制压到 −3.04/−4.18 dB，31 MHz 看入 119.78+j22.57 Ω（VSWR 2.50，不是 50 Ω 匹配），源阻抗 50→200 Ω 整链降 8.93 dB。故当前是**待进一步验证的 A+G22 候选**，不是验收通过的接收机。详见 [S05-06](simulation/v4_hardware/stage5_receiver/S05_06_A方案基带增益补偿与阻塞复验.md)。

2026-10-30 新增（S05-05）：S05 已定位邻近阻塞主要发生在检波处。约 2 MHz 有损 LC 方案显著改善 29/33 MHz 阻塞，10% 方波仍可恢复；RF 增益代价约 4.82 dB、原基带增益下输出约 2.43 Vpp。选频 A 保留 Q1/Q2，幅度补偿由 S05-06 承接。详见 [S05-05](simulation/v4_hardware/stage5_receiver/S05_05_R2邻近阻塞诊断与AB决策.md)。

截至 2026-10-29，S05 已形成 R2 独立候选：选频峰移到约 30.83 MHz、31 MHz 增益 68.44 倍；接入 BAT85/F1 与 TI OPA197 后，标称 10 mV/50 Ω、m=0.5 的预偏置方波输出约 4.78 Vpp。1.6 MHz 阻塞显著改善，但 29/33 MHz 邻近干扰、固定增益大输入过载、启动、BAT85S 型号与无线实测仍未闭合，**整机灵敏度和 6 m 距离不成立**。首批 R1 证据和冻结工程保留。S04 的独立 2N3904 振荡器标称假设模型通过末窗稳定性筛查，独立缓冲已开展带载探索；放大与隔离连接、晶体型号参数和整机电池端功耗尚未闭合。仿真结果不等于实物验收，详见各报告的条件和限制。

## 文件与复现

`simulation/` 保存工程、网表、脚本和测量摘要，`项目管理/` 保存计划与验证状态，`output/` 保存实验图册等交付物。

保留原有 Git 历史。按 `.gitignore`，大型原始波形（例如 `.raw`、`.gra`、`.npz`）、软件安装包及缓存不上传；部分证据仅保存在本机，摘要中留有路径或哈希。因此克隆本仓库不等于获得所有原始数据。运行脚本前需要安装相应软件并核对脚本中的本地路径；仓库不是开箱即用的软件包。
