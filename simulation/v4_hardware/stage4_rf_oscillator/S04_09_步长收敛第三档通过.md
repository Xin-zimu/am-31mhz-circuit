# S04-09 步长收敛：第三档通过（修正 S04-08 §5）

日期：2026-10-17。**本文修正 [S04-08](S04_08_C518062核查与独立模型.md) §5 中“步长收敛未验证”的结论。**

## 1. 为什么需要修正

S04-08 §5 写于 02:09，而步长收敛最细一档 `ng_2ms_003125ns` 在 **02:31:03** 才产出结果；
`comparison.json` 与 `evidence_manifest.json` 均生成于 **02:28:28**，早于该档完成。

因此当时的产物只包含两档对照，且：

```text
comparison.json 的 step_comparisons 只有 2 条：
  ng_2ms_025ns → ng_2ms_0125ns   numerical_screen_passed = false
  ng_2ms_0125ns → ng_2ms_00625ns numerical_screen_passed = false
```

报告据此写了“步长减半未取得有效波形、步长收敛未验证，频率位数不作精度保证”。
这在当时是**正确的**，但已被随后完成的数据**取代**：第 3 档实际跑通，且**通过**数值筛查。

## 3. 步长阶梯与二阶收敛

同一网表、**未改动任何元件或模型参数**（`no_component_or_model_parameter_changes: true`），2 ms、四档步长：

| 步长 / ns | f 偏差 / ppm | Vpp / V | P晶体 / μW | P电源5V / mW | 末尾100μs筛查 |
|---:|---:|---:|---:|---:|---|
| 0.025 | −198.673 | 0.613484 | 62.363 | 3.319315 | PASS |
| 0.0125 | −50.550 | 0.613539 | 62.349 | 3.319071 | PASS |
| 0.00625 | −13.502 | 0.613953 | 62.426 | 3.319794 | PASS |
| **0.003125** | **−4.238** | 0.613920 | 62.422 | 3.319742 | PASS |

每减半步长，频率偏差的**增量**依次为 148.12、37.05、9.26 ppm：

```text
相邻增量比 = 37.048 / 148.123 = 0.250
相邻增量比 =  9.264 /  37.048 = 0.250
```

比值稳定在 **0.250 = 2⁻²**，即**二阶收敛**（ngspice 默认 `trap` + `maxord=2` 的预期行为）。
Richardson 外推（p=2.000）给出步长→0 的频率偏差极限：

```text
用 0.025/0.0125/0.00625 ns  外推：−1.145 ppm
用 0.0125/0.00625/0.003125 ns 外推：−1.150 ppm
```

两条独立外推相差仅 0.005 ppm，**互相印证**。

## 4. 结论的更正

1. **“步长收敛未验证”作废**，改为：**步长收敛已验证，且为二阶收敛**，外推至零步长的频率偏差约 **−1.15 ppm**。
2. 先前报告的 −199 ppm（S04-08 表中 1 ms 的 −196.2 ppm 同源）**主要是数值步长误差**，不是电路或晶体特性。
   真实收敛值应在 **−1.15 ppm** 量级。
3. 幅度与晶体耗散对步长**不敏感**：四档 Vpp 极差约 0.00047 V（<0.08%），
   P晶体 极差约 0.077 μW（<0.13%）。**这两项可以直接用于后续比较，不必担心步长污染。**
4. 因此 **−1.15 ppm 仍不能与晶体 ±10 ppm 规格比较**：晶体参数（Cm/C0/Rm、模式）仍是假设值，
   `c518062_qualified=false` 不变。步长收敛解决的是**数值可信度**，不是**器件符合性**。

## 5. 仍然成立的部分

- 四档均通过末尾 100 μs 稳态筛查（幅度漂移 ~2.5×10⁻⁵、频率跨度 <0.05 ppm），
  **2 ms 工况确已进入稳态**，这一点不因本文而改变。
- 跨求解器一致性（[comparison.json](crosscheck_20261017/comparison.json) 的 `cross_solver_1ms`）：
  ngspice 与 Multisim 的频率差 0.0304 ppm、Vpp 差 −0.0043%、晶体耗散差 −0.0018%。仍然成立。
- 晶体参数未闭合、RE=4.7 kΩ 偏置属探索、小信号最弱组合裕量仅 1.056 倍 —— 均不变。
