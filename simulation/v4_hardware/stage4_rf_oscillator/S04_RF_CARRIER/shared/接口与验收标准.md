# 共用接口与验收标准（两条路线唯一口径）

更新：2026-10-29。来源：[S04-01 接口要求规格书](../../S04_01_接口要求规格书.md)。
**本文件不新增判据**，只把两条路线共用的口径集中一处，避免各自滑动。

## 1. 测量对象

目标节点 **TP2**（`EAM` 乘法器载波输入端）。所有载波指标在此节点测量。

## 2. 指标与阈值

| 指标 | 阈值 | 来源 | 性质 |
|---|---|---|---|
| 载波频率 | 30.69–31.31 MHz（±1%） | 评分标准表3 | **硬性** |
| 载波频率（优选） | ±31 kHz（±0.1%） | S04-01 §3 | 工程内控 |
| TP2 幅度 | 1.9–2.1 Vpp | D1 决议（1.000 V 峰值 ±5%） | 工程内控 |
| 负载 L_lo | 2 kΩ∥10 pF | D2 决议 | 占位假设 |
| 负载 L_hi | 10 kΩ∥10 pF | D2 决议 | 占位假设 |
| 负载牵引 | TP2 峰值变化 ≤10% | S04-01 §5.3 | 工程内控 |
| 谐波 | ≤ −20 dBc | S04-01 §6 | 工程内控 |
| 输出直流 | ≈ 0 V | S04-01 §6 | 硬性（EAM 对直流敏感） |
| 起振 | 自主起振并持续运行 | 用户 2026-10-29 | 硬性 |
| 整机功耗 | 电池端 < 0.5 W，含稳压损耗 | 评分标准表3 | **硬性** |

**±0.1% 不得替代 ±1% 作为合格判据。**

## 3. 起振判定方法（两条路线必须相同）

```
1) 电感/晶体必须具备有限损耗，禁止理想无损元件
2) UIC 冷启动 或 在稳定直流工作点施加受控小扰动（记录幅值与方式）
3) 观察窗口 ≥ 1.5 ms（推荐 3 ms）
4) 判定：包络在后期自主增长并进入稳定等幅
5) 必须同时运行正对照（晶体电路），确认框架能识别起振
```

**依据**：晶体自身在 600 µs 窗口内仍不可见，约 0.8 ms 才开始明显增长；短于 1.5 ms 的窗口会把已知可起振的电路误判为失败。

## 4. 禁止使用的"通过证据"

- 理想无损电感（Rs=0）下的持续振铃
- 未加正对照的单次"不起振"结论
- 移除谐振回路后的阻抗/负阻测量（Colpitts 中该操作同时破坏反馈）
- 浮空节点的 `op` 结果
- 仅凭文件名含 steady/final 的结论

## 5. 必须单独记录的量

起振时间、谐波（H2/H3）、5 V 端与整机电池端功耗（分开）、实物可调范围、测量时的步长与容忍设置。
