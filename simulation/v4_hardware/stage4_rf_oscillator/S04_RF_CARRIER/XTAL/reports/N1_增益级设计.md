# N1：31 MHz 晶体主线增益级设计

日期：2026-10-29。状态：**仿真设计点已达成 TP2 指标；未做实物验证，未接入主工程。**
上游：[S04_RF_CARRIER/README](README.md)、[comparison.md](comparison.md)。

## 1. 任务与判据

晶体主线（A）的唯一阻塞是**幅度**：振荡器射极 0.531 Vpp，经射随器 + 2 kΩ∥10 pF 后仅 0.415 Vpp，
而 TP2 要求 **1.9–2.1 Vpp**，缺口约 4.8 倍。本任务设计补齐这一级。

| 判据 | 目标 | 来源 |
|---|---|---|
| TP2 幅度 | 1.9–2.1 Vpp | D1 决议（工程内控） |
| 谐波 | ≤ −20 dBc | S04-01 §6（内控） |
| 负载 | 2 kΩ∥10 pF 最坏、10 kΩ∥10 pF 上界 | D2 决议 |
| 供电 | 5 V | D3 决议 |
| 输出直流 | ≈ 0 V | S04-01 §6（`EAM` 对直流敏感） |

## 2. 设计点

```
共射放大器 + 部分射极旁路
VCC = 5 V
R1 (VCC→B)  = 22 kΩ
R2 (B→GND)  = 4.7 kΩ
RC (VCC→C)  = 1 kΩ
RE1 (E→GND, 不旁路) = 68 Ω
RE2 (E→GND, 旁路)   = 220 Ω
CE  (旁路 RE2)      = 100 nF
CIN (输入耦合)      = 10 nF
COUT(输出耦合)      = 10 nF
负载 = 2 kΩ ∥ 10 pF
```

## 3. 结果

### 3.1 标称点

| 量 | 值 |
|---|---:|
| 输入 | 0.265 V 峰值（0.530 Vpp） |
| **输出** | **2.0413 Vpp** |
| 增益 | 3.85 倍 |
| 输出直流 | ≈ 0 V（经 COUT 隔直） |
| **THD** | **6.08 %（−24.3 dBc）** |
| 5 V 端功耗 | 13.4 mW |

**两项指标同时达标**：幅度落在 1.9–2.1 Vpp 窗口内，谐波优于 −20 dBc 内控线。

### 3.2 敏感度

| 条件 | 输出 | 相对标称 |
|---|---:|---:|
| 标称 5 V / 27 ℃ / 2 kΩ∥10 pF | 2.0413 Vpp | — |
| 负载 10 kΩ∥10 pF（上界） | 2.1872 Vpp | **+7.1 %** |
| 负载 1 PΩ（仿真开路） | 2.1953 Vpp | **+7.5 %** |
| 温度 0 ℃ | 1.9031 Vpp | −6.8 % |
| 温度 50 ℃ | 2.1224 Vpp | +4.0 % |
| 电源 4.75 V | 1.9046 Vpp | −6.7 % |
| 电源 5.25 V | 2.1513 Vpp | +5.4 % |

**负载牵引 +7.5 %，在 S04-01 §5.3 的 10 % 内控线内。**
温度 −50…+50 ℃ 与电源 ±5 % 的合计最坏偏移约 −13.5 %，
会把 2.04 Vpp 拉到 1.77 Vpp，**跌出 1.9–2.1 窗口**——见 §5 边界。

## 4. 设计过程与关键发现

### 4.1 全旁路方案失真不可接受

最初用射极完全旁路（CE 直连 E），增益充足但不线性：

| 配置 | 输出 | THD |
|---|---:|---:|
| RC=1k RE=220（全旁路） | 2.69 Vpp | **49.2 %** |
| RC=1k RE=330（全旁路） | 1.96 Vpp | **51.2 %** |

原因不是偏置错误，而是**摆幅触顶**：`Vc` 摆到 2.56…4.52 V，逼近 5 V 轨。
线性区实测：小信号增益 7.74 倍，大信号只剩 3.70 倍——即增益被削掉一半。

### 4.2 部分旁路是解法

把 RE 拆成 `RE1`（不旁路，产生本地负反馈稳定增益）+ `RE2`（旁路，保住交流增益）：

| RE1 | 输出 | THD | dBc |
|---:|---:|---:|---:|
| 47 Ω | 2.71 Vpp | 6.86 % | −23.3 |
| 62 Ω | 2.20 Vpp | 6.30 % | −24.0 |
| **68 Ω** | **2.04 Vpp** | **6.08 %** | **−24.3** |
| 75 Ω | 1.88 Vpp | 5.84 % | −24.7 |

RE1 从 47→75 Ω，THD 单调改善，幅度单调下降——这是可调的设计自由度，实物可用电位器微调。

## 5. 边界与未覆盖（不得隐去）

1. **温漂+电源最坏组合会跌出窗口**：0 ℃ 且 4.75 V 同时发生约 −13.5 %，2.04→1.77 Vpp。
   实物需实测，必要时加温度补偿或改用可调偏置。
2. **2N3904 用的是 UNCG 教学模型**，不是到货批次。增益与 THD 会随实际 h_FE 变化。
3. **未接入振荡器**：本设计用理想 31 MHz 源驱动，未验证对振荡器的负载牵引与起振影响。
4. 未做**步长收敛**（只用 0.0625 ns），未做多档步长对照。
5. 未做**实物**：无布局寄生、无元件公差、无温度实测。
6. 输出直流经 COUT 隔直后 ≈ 0 V，但**未加直流复位电阻**，见 S04-01 §6 要求。
7. 功耗 13.4 mW 是**本级 5 V 端**，不是整机电池端。
