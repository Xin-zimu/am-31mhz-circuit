# S04_RF_CARRIER：31 MHz 载波双路线并行研发

建立日期：2026-10-29。决策依据：用户在 2026-10-29 明确采用**双路线并行**，不立即在晶体与 LC 之间做主选择。

## 路线定义

| 路线 | 构成 | 当前定位 | 已有证据 |
|---|---|---|---|
| **A 主线：晶体** | C518062 + 2N3904 Colpitts | **当前主线**，不提前切换 | S04-11、S04-12、S04-13 |
| **B 备选：LC** | 2N3904 + LC Colpitts | 独立验证中，未提升为同级候选 | S04-13、S04-LC-02、S04-LC-02b |

两条路线**独立设计、独立验证**，只共用接口与验收指标。

### 主线 N1（31 MHz 增益级）当前状态：**未通过**

| 指标 | 结果 | 状态 |
|---|---|---|
| TP2 幅度 2 kΩ 档（0.530 Vpp 输入） | 2.0413 Vpp | 通过 |
| TP2 幅度 10 kΩ 档 | 2.1872 Vpp | **失败**（超 2.1 上限） |
| TP2 幅度，真实 0.415 Vpp 输入 | 1.6706 Vpp | **失败**（低于 1.9 下限） |
| 谐波 | −24.3 dBc | 通过 |
| 输入阻抗 | **318 Ω**（要求 ≥100 kΩ） | **失败**（Miller 效应，共射拓扑结构性冲突） |

提交 9338b76 的网表本身有连接错误（集电极接 vcc，输出恒 0 V），已在新提交中更正，
历史不改写。详见 [XTAL/reports/N1_复核与更正.md](XTAL/reports/N1_复核与更正.md)。

### 主线 C1（三模块首轮级联）当前状态：**已跑通，两项未达标**

晶体 Colpitts ─[1nF]→ 射随缓冲 ─[1nF]→ 共射增益级（RE1=56 Ω）─[10nF]→ TP2。

| 指标 | 结果 | 状态 |
|---|---|---|
| 自主起振（两档负载） | 是 | 通过 |
| 频率 ±1% | **30.99892 MHz（−0.0035%）** | 通过（C3 校正后） |
| 加载引起频率变化（D5-a） | −1～−2 Hz（−0.000006%） | **仅"两档同跑"有效**；真正的 D5-a 未做 |
| TP2 2 kΩ 档 | **1.9995 Vpp**（C3 收敛值） | 通过 |
| TP2 10 kΩ 档 | 2.0864 Vpp（C2，未收敛网格） | **撤销"通过"，改判 N/A** |
| 幅度随负载变化 | +5.67%（未收敛网格） | **待重测** |
| H2 | −19.10 / −19.57 dBc（未收敛网格） | **未达标；且需在新网格重测** |
| H3 | −34.6 dBc | 通过 |
| TP2 直流 | −0.002 mV | 通过 |

> **C3（2026-10-30）推翻了 C2 的判定基础。** C2 把 gear/trap 的 18.1 kHz、37% 分歧列为"两个不同的解"，
> C3 证明它是**同一个解被两种积分器以不同误差读出**：
> 频率误差 = (ωh)²/12（trap）与 (ωh)²/3（gear），比例恒为 4:1，实测与理论吻合到 0.1%，
> 且能用解析 RLC 电路在晶体 Q=17118 上定量复现。
> 扣除后，八个独立设置（0.0625～0.5 ns × 两种方法）收敛到 **30.99892 MHz**。
> 幅度上 gear 的数值阻尼把数值 Q 压到与晶体 Q 同量级，这是它 1.24 Vpp 甚至不起振的原因。
>
> **因此 10 kΩ 档不能维持"通过"**：C2 的 2.0864 是未收敛网格上的采样。
> 详见 [XTAL/reports/C3_数值一致性验证.md](XTAL/reports/C3_数值一致性验证.md)。

**D5-a 尚未完成。** C1/C2 测的是"同一链路切换 RLOADG"，误差共模抵消所以 −1～−2 Hz 可信；
但 D5-a 要的是"裸振荡器 → 接入缓冲后级"的牵引，属跨运行比较，误差不共模，
必须先各自扣掉积分器误差才能做。

## 共用接口（唯一，不因路线而变）

目标节点 **TP2**，来自 [S04-01 接口要求规格书](../S04_01_接口要求规格书.md)：

| 参数 | 要求 | 性质 |
|---|---|---|
| 频率 | **31 MHz ±1%（30.69–31.31 MHz）** | 课程标准 |
| 振荡器加载前后频率变化 | 测量并记录；优选 ≤0.1% | D5-a 优选（**不替代 ±1%**） |
| 加载后起振可靠性 | 仍能自主起振并稳定等幅 | D5-b **硬性** |
| 频率（优选） | ±0.1%（±31 kHz） | **工程内控，不得替代 ±1%** |
| TP2 幅度 | **1.9–2.1 Vpp**（1.000 V 峰值 ±5%） | 工程内控口径 |
| 测试负载 | **2 kΩ∥10 pF**（最坏）、**10 kΩ∥10 pF**（上界） | D2 占位假设 |
| 起振 | 自主起振并持续运行 | — |
| 稳定度 | 电源、温度、负载三方向 | — |
| 实物可行性 | 可购买、可调试、可在万能板搭建 | 评分标准要求 |
| ~~输入阻抗 ≥100 kΩ~~ | **已取消**，改为实测加载效应 | D5，见 [S04-14](../S04_14_接口指标修订_输入阻抗.md) |

**另需单独记录**：起振时间、谐波（≤ −20 dBc 内控）、功耗、实物可调范围。

## 纪律

1. 不得用理想无损元件（Rs=0 电感、理想源）作为"器件级通过"证据。
2. 任何"起振"结论必须伴随正对照（已知能起振的电路）在同一判据下通过。
3. 判据阈值改动必须写明理由，并保留改前的原始数据。
4. 两条路线的对比只在**同一接口、同一测量方法**下进行。
