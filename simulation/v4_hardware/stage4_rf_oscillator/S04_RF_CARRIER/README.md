# S04_RF_CARRIER：31 MHz 载波双路线并行研发

建立日期：2026-10-29。决策依据：用户在 2026-10-29 明确采用**双路线并行**，不立即在晶体与 LC 之间做主选择。

## 路线定义

| 路线 | 构成 | 当前定位 | 已有证据 |
|---|---|---|---|
| **A 主线：晶体** | C518062 + 2N3904 Colpitts | **当前主线**，不提前切换 | S04-11、S04-12、S04-13 |
| **B 备选：LC** | 2N3904 + LC Colpitts | 独立验证中，未提升为同级候选 | S04-13、S04-LC-02、S04-LC-02b |

两条路线**独立设计、独立验证**，只共用接口与验收指标。

## 共用接口（唯一，不因路线而变）

目标节点 **TP2**，来自 [S04-01 接口要求规格书](../S04_01_接口要求规格书.md)：

| 参数 | 要求 | 性质 |
|---|---|---|
| 频率 | **31 MHz ±1%（30.69–31.31 MHz）** | 课程标准 |
| 振荡器加载前后频率变化 | 测量并记录；优选 ≤0.1% | D5-a 优选（**不替代 ±1%**） |
| 加载后起振可靠性 | 仍能自主起振并稳定等幅 | D5-b **硬性** |
| 频率（优选） | ±0.1%（±31 kHz） | **工程内控，不得替代 ±1%** |
| TP2 幅度 | **1.9–2.1 Vpp**（1.000 V 峰值 ±5%） | 工程内控口径 |
| 测试负载 | **2 kΩ∥10 pF**（最坏）、**10 kΩ∥10 pF**（上界） | D2 占位假设 |
| 起振 | 自主起振并持续运行 | — |
| 稳定度 | 电源、温度、负载三方向 | — |
| 实物可行性 | 可购买、可调试、可在万能板搭建 | 评分标准要求 |
| ~~输入阻抗 ≥100 kΩ~~ | **已取消**，改为实测加载效应 | D5，见 [S04-14](../S04_14_接口指标修订_输入阻抗.md) |

**另需单独记录**：起振时间、谐波（≤ −20 dBc 内控）、功耗、实物可调范围。

## 纪律

1. 不得用理想无损元件（Rs=0 电感、理想源）作为"器件级通过"证据。
2. 任何"起振"结论必须伴随正对照（已知能起振的电路）在同一判据下通过。
3. 判据阈值改动必须写明理由，并保留改前的原始数据。
4. 两条路线的对比只在**同一接口、同一测量方法**下进行。
