## 0. 为什么这一步不能跳过、也不能用仿真替代

AM-ALT.3 目前的全部结论**都建立在一个未实测的数字上**：1.00 m 单极子的等效电容 `C_ant = 8.913 pF`。这是 Schelkunoff 传输线近似的**公式估算**，不是测量。

它有多不可靠，项目自己已经量化过：

| C_ant | 需要的调谐电感 | 相对标称 |
|---:|---:|---|
| 6.00 pF | 4.393 µH | −26% |
| **8.913 pF（估算）** | **2.957 µH** | 0%（设计点） |
| 12.00 pF | 2.197 µH | +26% |

也就是说，**一根 1 m 导线在桌上的实际对地电容，随高度、地网大小、附近金属、手握状态变化，就能跨越 2 倍的电感范围**。而主报告第 7 节已量化：C 偏 ±15% 会让天线电流掉到约 **1/3**。

更关键的是：**天线电流掉到 1/3 时，调制波形几乎不变**（22.5% / 28.3% / 28.2%）。这意味着**看波形正常完全不能证明调谐正确**——必须测电流，而电流正比于 `C_ant` 是否准。所以这一步是 AM-ALT.3 的**出口条件**，不是可延后的备注。

## 1. 测量目标与验收判据

| 量 | 目标 | 判据 |
|---|---|---|
| `C_ant`（等效串联电容） | 目标 **±3%** | 计算器输出的 `C_ant_tol_pct_quadrature ≤ 3.0` |
| `R_total`（含辐射电阻 + 线圈损耗 + 地损耗） | 报告实测值与不确定度 | **不设 ±3% 判据**，理由见 §1.1 |
| 调谐范围 | 确认可跨过 31 MHz 电流峰 | 实物可调范围覆盖 `L_required(31 MHz, C_ant_实测)` |

### 1.1 为什么 `R_total` 不设 ±3% 判据

串联谐振法测的是**整个回路的电阻之和**：

```
R_measured = R_rad + R_coil + R_ground + R_contact
```

它**无法把辐射电阻 4.224 Ω 从线圈损耗 9.6 Ω 里分离出来**（`02_勘误` §7.3 已明确列出这一局限）。所以：

- 报 `R_total` 的**实测值与不确定度**是有意义的（它决定 Q、带宽、以及 5.30 mA 需要多少端口电压）；
- 但"R_total 达到 ±3%"不是一个可判定的目标，因为其中哪一部分算"对"本身无定义。

**±3% 只对 `C_ant` 有意义**——它是唯一决定调谐电感的量。

## 2. 接线（三种配置，按顺序执行）

### 2.1 通用规则（违反即数据作废）

1. **绝不在天线节点接探头。** 16 pF 探头并在 8.91 pF 天线上 = **+180%**，谐振从 31.0 MHz 拉到 **18.5 MHz**。看起来测了，其实测的是探头。
2. **10 Ω 取样电阻两端都不接地**，用两通道分别测两端，`CH1−CH2` 得到电阻电压。**两根地夹都只接同一个公共地**，绝不能把地夹接到电阻的任一"非地"端。
3. 两支探头先在**同一节点**并联校正：增益差、延迟差、相减残差。**残差 > 5% 时本次数据不满足 ±3% 目标**，必须重新调零。
4. 固定并记录：天线高度、线径、地网尺寸、支撑物、同轴走向、附近金属、与人的距离。**换状态就必须重测。**
5. 保留仪器保护接地。不要为了"简单"把取样电阻挪进地网回路——地网、同轴外皮、仪器接地会旁路并改变天线本体。

### 2.2 配置 A：低频电感标定（双电容法）

```
发生器 ──[ 被测 L ]──[ 100 pF 或 220 pF 标准电容 ]──[ 10 Ω ]── 公共地
                                                        │
                                              探头尖端 ─┘（地夹接公共地）
```

- 两个电容在**同一位置**替换，线圈抽头、位置、连线**完全不动**。
- 每个配置测 **3 次重复读数**，记录峰两侧频点（`f_low`、`f_high`），谐振取 `(f_low+f_high)/2`。
- 预期频率约 **5～11 MHz**（覆盖 2.2～4.4 µH 全范围），不是 6～9 MHz。
- 先用小幅度激励确认线性，再提高幅度。
- **按实测源幅度归一化取样电压**，避免发生器幅频响应使电流峰偏移。

测 3 个调谐位置（低/中/高），每个位置都要做这套双电容标定。

### 2.3 配置 B：天线谐振测量

```
发生器 ──[ 10 Ω 取样 ]──[ 可调 L ]──┬── 1.00 m 天线
                                     │
                                  （对机壳/地网电容）
```

- 固定载波幅度，**扫频找 10 Ω 上电压最大的频点**即为串联谐振。
- 记录：`f_res`、`V_sense`（rms）、`V_emf`（发生器设定值，注明是"开路"还是"50 Ω 负载"显示）、`CH1−CH2` 残差。
- 在 31 MHz 固定载波下**调节 L 找电流最大值**，记录该位置的 L（调峰位置）。

### 2.4 配置 C：31 MHz 调峰确认

在配置 B 的接线上，把发生器固定到 31 MHz，调节 L 使 `V_sense` 最大。记录：
- 该 L 位置（与配置 A 的标定位置对应）
- 峰值 `V_sense`
- 偏离 ±20 kHz、±100 kHz 时的 `V_sense`（用于估 Q 与带宽）

## 3. 计算链（计算器已实现，勿手算）

### 3.1 从双电容标定求 L 与杂散电容

```
1/(ω₁²L) = C₁ + C_s
1/(ω₂²L) = C₂ + C_s
=>  L = (1/ω₁² − 1/ω₂²) / (C₁ − C₂)
    C_s = 1/(ω₁²L) − C₁
```

### 3.2 从天线的谐振频率求 C_ant

```
C_total = 1 / ((2π f_res)² L)
C_ant   = C_total − C_s
```

### 3.3 从取样电压求回路电阻

```
I       = V_sense / 10 Ω
R_total = V_emf / I − R_gen − R_sense
```

`R_gen = 50 Ω`（发生器源电阻，**与面板显示无关**）。`V_emf` 必须是**开路电动势的 rms 值**：若面板按 50 Ω 负载显示，则该显示值就是 EMF；若按高阻显示，则也是 EMF。**同一次计算里不能混用两种约定。**

### 3.4 不确定度

```
dC/C = −2·(df/f) − (dL/L)        频率以平方进入，是主导项
```

按两种方式各报一次：
- **正交合成** `sqrt((2df/f)² + (dL/L)²)` —— 误差独立时的期望值
- **线性相加** `2|df/f| + |dL/L|` —— 最坏情况

**判据用正交值 ≤ 3%，同时报告线性值。** 两者都 ≤3% 才写"满足 ±3%"，只有正交值 ≤3% 时写"满足 ±3%（正交口径）"。

### 3.5 L 的不确定度：绝对容差，不是百分比

这是最容易搞错的一处。`L = (A₁−A₂)/(C₁−C₂)`，误差来自**电容差**：

| 电容对 | 每只 ±0.25 pF 时的 `dL/L` | 可用性 |
|---|---:|---|
| **100 / 220 pF** | **±0.36%** | ✅ 采用 |
| 4.7 / 6.8 pF（带内） | **±16.8%** | ❌ 弃用 |

计算器自检独立复现了这两个数。**注意：把容差写成"百分比"会完全掩盖这个差异**——两只电容的相对误差相同，但进入 L 的是**绝对差值**。这正是 `02_勘误` §7.2 说的"带内方案误差 20%"的来源。

## 6. 什么情况必须重测

| 情况 | 原因 |
|---|---|
| `CH1−CH2` 残差 > 5% | 差分相减不可信 |
| 正交不确定度 > 3% | 未达目标；先改进最大项（通常是 L，用更大电容步长） |
| `C_ant` ≤ 0 或 > 20 pF | 非物理，检查 `C_s` 与 L |
| 谐振峰不明显（Q 太低） | 检查取样电阻是否被旁路、地网是否失效 |
| 换了天线高度/地网/位置/附近物体 | 阻抗随状态变化，必须重测 |
| 从台面供电改为电池独立工作 | 地回路改变，必须重新检查调谐 |
