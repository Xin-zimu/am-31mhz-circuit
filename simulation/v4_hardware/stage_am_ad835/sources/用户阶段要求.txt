# Stage AM-AD835：基于 AD835 的 31MHz 实际调幅电路开发与可行性验证

你现在接手一个正在进行的 31MHz AM 无线收发电路课程项目。

本任务不是简单地画一个 AD835 典型应用电路，而是要基于项目已有的真实仿真数据、原始 POLY(3) 调制模型、31MHz 晶体振荡器、接收端指标和整机功耗约束，独立设计并验证一条基于 AD835 的实际调幅技术路线。

请将自己视为负责该项目的模拟射频电路工程师。

**本阶段的首要目标：验证 AD835 能否直接完成 31MHz、20kHz 方波的 AM 调制，并在规定负载下达到原项目的输出指标。**

在验证完成之前，不采购、不焊接、不修改原有已冻结电路。

# 一、项目背景与现有技术路线

## 1.1 项目目标

本项目需要实现一条真实的 31MHz AM 发射与接收链路。

基本信号参数：

| 参数 | 数值 |
|---|---:|
| 载波频率 | 31MHz |
| 基带频率 | 20kHz |
| 基带输入幅度 | 1～4Vpp |
| 基带占空比 | 10%、30%、50% |
| 原始载波测试点 | TP2 |
| TP2 参考输出 | 约2Vpp |
| 目标调制方式 | 普通带载波 AM |
| 原始理想调制模型 | POLY(3) |

现有项目已经完成晶体振荡器和接收端的大量仿真工作。

接收端采用二极管检波、RC 滤波和 OPA197 放大整形。

项目此前的接收端选频带宽约为1.919MHz。

整机功耗预算：不超过500mW。请从正式项目任务书和最新报告中重新核实该约束及其测量口径。

## 1.2 原始调幅模型

原工程使用 POLY(3) 实现理想调幅。

已有模型表达式：

V_AM = V_c × (0.6 + 0.1 × V_m)

其中：

- V_c：31MHz载波瞬时电压。
- V_m：20kHz基带瞬时电压。
- 0.6：载波基准系数。
- 0.1：调制灵敏度系数。

在基带为0～4V的单极性方波时：

| 基带高电平 | 载波包络高电平 | 载波包络低电平 | 理论调制度 |
|---|---:|---:|---:|
| 1V | 0.7Vc | 0.6Vc | 7.69% |
| 2V | 0.8Vc | 0.6Vc | 14.29% |
| 3V | 0.9Vc | 0.6Vc | 20.00% |
| 4V | 1.0Vc | 0.6Vc | 25.00% |

注意：上表假定基带是0～Vpp的单极性方波。

必须检查原工程中的实际信号源定义，包括 PULSE 的 V1、V2、TD、TR、TF、PER 等参数。

如果原信号并非0～Vpp，必须以原网表为准重新推导映射关系，不能直接套用上表。

**POLY(3) 是本次 AD835 设计必须对齐的数学参考，不能擅自改变其调制规律。**

# 四、AD835 的调幅原理及具体设计任务

AD835 的传递函数：

W = ((X1-X2) × (Y1-Y2)) / U + Z

其中：

- X = X1-X2：调制控制输入。
- Y = Y1-Y2：31MHz载波输入。
- Z：载波直通叠加输入。
- W：调制后的输出。
- U：内部比例系数，标称约1.05V。

AD835 数据手册第11页 Figure 23 给出了直接 AM 调制应用。

请仔细阅读并复现 Figure 23，不要仅根据文字描述自行猜测接线。

## 4.1 首选实现：复现原 POLY(3) 调制规律

目标：

W = Vc × (0.6 + 0.1Vm)

如果采用：

Y = Vc

Z = Vc

那么：

W = Vc × (1 + X/U)

因此：

X = U × (0.1Vm - 0.4)

使用 U=1.05V：

X = 0.105Vm - 0.42V

当 Vm 为0～4V时：

| Vm | X输入 |
|---:|---:|
| 0V | -0.420V |
| 1V | -0.315V |
| 2V | -0.210V |
| 3V | -0.105V |
| 4V | 0V |

此时：

- Vm=0：W=0.6Vc。
- Vm=4：W=1.0Vc。

理论调制度为25%。

这是本次优先研究的实现方式。

需要设计20kHz基带信号的电平转换与偏置网络，使其能够把原始基带信号转换为X输入要求的电压。

不能直接把0～4V信号未经处理接入X1。

## 4.2 备选实现：调整 Z 输入的载波幅度

还可以研究：

Y = Vc

Z = 0.6Vc

X = 0.105Vm

同样可以得到：

W = Vc × (0.6 + 0.1Vm)

比较两种实现方式：

A. Z直接接入载波，X采用负偏置调制信号。

B. Z接入经过0.6倍衰减的载波，X采用正向调制信号。

比较：

- 外围元件数量。
- 输入源加载。
- 31MHz相位一致性。
- X、Y、Z的实际输入范围。
- 调制度误差。
- 载波泄漏。
- THD。
- 实际焊接难度。

选择综合表现更好的方案。

## 4.3 载波输入设计

现有 TP2 输出约2Vpp、31MHz。

需要将同一载波信号提供给：

- Y1（Pin 1）。
- Z（Pin 4）。

Y2（Pin 2）接模拟地。

必须分析载波分配网络：

1. Y输入与Z输入并联后的实际负载。
2. Y输入100kΩ∥2pF。
3. Z输入60kΩ∥2pF。
4. 载波分支电阻及衰减网络。
5. 两条载波路径的相位差。
6. 对原晶体振荡器TP2的加载影响。

不能假设理想信号源能够无限驱动两个输入。

特别注意：2Vpp对应1V峰值，正好达到X/Y差分输入标称±1V范围。需要对载波输入幅度进行扫描，检查失真和输出余量。

## 4.4 AD835 引脚接线

必须在报告中给出完整引脚表：

| 引脚 | 名称 | 本项目用途 |
|---|---|---|
| 1 | Y1 | 31MHz载波输入 |
| 2 | Y2 | 模拟地 |
| 3 | VN | -5V |
| 4 | Z | 载波直通或0.6倍载波 |
| 5 | W | AM输出 |
| 6 | VP | +5V |
| 7 | X2 | 模拟地 |
| 8 | X1 | 20kHz调制控制输入 |

特别检查：

- 不要把3脚和6脚接反。
- 不要将Z脚悬空。
- 不要将W脚直接接地。
- 所有输入信号必须使用正确的公共参考地。
- X1、Y1和Z的直流工作点必须检查。

# 五、供电系统设计

这是本项目的重要约束。

AD835标准工作方式采用±5V双电源。

不能把普通单路+5V稳压模块直接当成完整供电方案。

请先检查项目现有电池和稳压模块计划，再设计供电。

需要比较：

方案A：电池输入 → +5V降压模块 + -5V反相DC-DC模块。

方案B：电池输入 → 双路输出DC-DC模块。

方案C：如果存在合理依据，研究单电源供电及外围偏置修改，但必须按照数据手册重新验证，不能直接把单电源接法视为等效方案。

基准设计先采用±5V。

## 5.1 电源去耦

严格参考 AD835 数据手册 Figure 20。

每条电源轨需要考虑：

- 铁氧体磁珠。
- 4.7μF电容。
- 0.01μF陶瓷电容。
- 紧贴芯片电源引脚布置。
- 合理的模拟地回流路径。

Figure 23省略了去耦元件，但实际电路必须补齐。

检查电容的封装、ESR、自谐振频率及布局影响。

## 5.2 功耗预算

整机功耗目标不超过500mW。

请分别计算：

1. AD835正电源功耗。
2. AD835负电源功耗。
3. DC-DC模块转换损耗。
4. 基带电平转换电路功耗。
5. 晶体振荡器功耗。
6. 其他保留模块功耗。
7. 最终电池输入功耗。

不能只把16mA乘以5V作为整机功耗。

必须根据数据手册供电电流定义和实际仿真模型，分别核算正负电源电流。

典型和最大静态电流都需要列入预算。

如果AD835路线使整机超过500mW，必须明确报告，不能通过忽略DC-DC损耗来宣称满足要求。

## 6.3 必须验证 AD835 模型本身

不要直接开始完整收发机仿真。

先做以下基础测试：

测试A：基本乘法器。

验证：

W = XY/U + Z

改变X、Y、Z，确认模型传递关系正确。

测试B：Figure 23 AM调制器。

严格按照数据手册Figure 23建立电路，输入低频测试信号，验证高低包络关系。

测试C：31MHz实际调幅。

将载波改为31MHz，调制信号改为20kHz方波。

确认模型能够稳定计算31MHz载波及其调制边带。

测试D：输出驱动。

接入50Ω负载，检查输出幅度、波形失真及输出电流。

完成以上四项后，才进入完整测试矩阵。

# 七、完整测试矩阵

本阶段必须完成以下测试。

## 7.1 输入条件

| 参数 | 测试值 |
|---|---|
| 载波频率 | 31MHz |
| 载波幅度 | 参考TP2约2Vpp |
| 基带频率 | 20kHz |
| 基带幅度 | 1、2、3、4Vpp |
| 占空比 | 10%、30%、50% |

基带源的高低电平必须与原工程一致。

## 7.2 负载条件

至少测试：

1. 2kΩ∥10pF。
2. 10kΩ∥10pF。
3. 50Ω。
4. 50Ω∥10pF。

额外增加50Ω下的输出电容扫描：

- 0pF。
- 2pF。
- 5pF。
- 10pF。

重点验证10pF负载，因为它超过数据手册50Ω最大摆幅图所采用的CL≤5pF条件。

不得直接依据数据手册的50Ω摆幅图认定10pF负载下也一定能够达到目标。

## 7.3 输出测量

每种输入和负载组合都需要记录：

- 高电平包络V_H。
- 低电平包络V_L。
- 调制度m。
- 完整周期平均包络。
- 输出最大值与最小值。
- 载波THD。
- 载波幅度。
- 输出直流偏置。
- 输入和输出功率。

调制度计算：

m = (V_H - V_L) / (V_H + V_L)

注意：

高、低包络是31MHz载波的峰峰值，不是20kHz包络信号本身的峰峰值。

## 7.4 线性度

将AD835与原POLY(3)在完全相同的输入和负载条件下比较。

对于1～4Vpp：

- 不能要求所有输入都保持25%调制度。
- 必须复现原始POLY(3)的调制规律。
- 比较每种输入下的高低包络。
- 比较包络变化量与基带幅度之间的关系。

建议内部验收：

- 4Vpp、50%占空比时调制度目标25%±2个百分点。
- 包络变化量相对POLY(3)误差不超过5%。
- 10%、30%、50%占空比均能正常工作。
- 不允许明显过调制、削顶或载波丢失。

## 7.5 瞬态与周期稳态

20kHz周期为50μs。

10%占空比时高电平持续时间只有5μs。

因此：

1. 仿真必须覆盖足够多的20kHz周期。
2. 不得将启动瞬态当成稳定波形。
3. 必须检查电平切换后的包络建立时间。
4. 必须记录10%占空比下的短脉冲响应。
5. 对稳态平台进行独立测量。
6. 需要明确仿真最大步长，并保证31MHz载波采样精度。

建议对比多个最大步长，确认结果不依赖仿真步长。

## 7.6 频谱分析

重点检查：

- 31MHz载波。
- 31MHz±20kHz。
- 31MHz±60kHz。
- 31MHz±100kHz。
- 其他20kHz整数倍边带。
- 谐波和非谐波杂散。

将输出频谱与接收端约1.919MHz选频带宽联系起来。

检查AD835的31MHz幅相响应是否影响20kHz方波包络的边沿。

不要把250MHz标称带宽直接等同于31MHz下完全平坦。
