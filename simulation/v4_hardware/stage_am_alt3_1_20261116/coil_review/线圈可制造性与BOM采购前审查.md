# AM-ALT.3.1-R1｜线圈可制造性与 BOM 采购前审查

2026-11-16。结论：**三指标在同一空心线圈上有合理的共同可行区，但现有证据不足以放行“已定型、可免验证制作”的线圈。原 16 匝、25 mm 中心直径、35 mm 轴长初值需要修订；整套 BOM 暂不作为最终采购放行单。**

本次是计算、文献与文件审查，未绕制、未采购、未焊接、未修改冻结电路。上一轮 NEC 对天线地网的验证不等于对实际螺旋线圈的验证：其调谐线圈是 **LD 集中参数负载**，Q30/60/100 是输入条件，未从实际绕组求得。

## 1. 三项指标必须如何定义

| 指标 | 本次采用的共同口径 |
|---|---|
| 3.48996 µH | **31 MHz 线圈端口有效串联电感** Im(Zcoil)/(2πf)，即 X≈+679.77 Ω；不是低频 LCR 表读数，也不是 Wheeler 几何值 |
| Q≥60 | 同一安装、同一抽头、同一31 MHz端口的 Im(Zcoil)/Re(Zcoil)；不包含外部10 Ω取样电阻和天线损耗 |
| SRF≥62 MHz | 线圈组件在规定安装边界下的**首次本征自谐振**；不包括天线容抗形成的31 MHz串联谐振，也不包括外接100/220 pF的测量谐振 |

自谐振 62 MHz 是上一轮自行设定的两倍工作频率工程裕量，**不是课程原文指标**。本次保留它进行共同可行性审查，没有通过悄悄降低门槛来“通过”。最终三项必须来自同一线圈最终状态，不能分别引用不同抽头、长度、夹具上的最好数值。

## 2. 共同约束：总寄生电容不能无限增加

采用一阶模型：Zcoil = (Rac+jωL0) ∥ Cp ∥ Rp；其中 Rp 代表介质等并联损耗。Cp 是折算到同一参考端口的总有效电容，包含绕组自容、端子及安装影响；多节点真实环境只有在端口等效模型成立时才可这样合并。

先忽略小损耗，设 u=ω²L0Cp=(31 MHz/fSRF)²：

```text
Leff = L0/(1-u)
fSRF >= 62 MHz  => u <= 0.25
Leff = 3.48996 µH
=> 2.61747 µH <= L0 <= 3.48996 µH
=> Cp,total <= 2.51753 pF
Qterminal >= 60 => ESRterminal <= 679.77/60 = 11.3295 Ω
```

**2.52 pF 是总预算，不是允许另加2.52 pF。** 当自谐振恰好62 MHz时，若只考虑串联铜损，绕组内部Rac需约≤6.373 Ω，因为并联自容会把端口串联等效电阻放大；这时内部绕组 Q0 约需≥80，才能使端口 Q≥60。存在介质损耗时，可分给铜损的预算还要减少。以上边界是高Q一阶近似；脚本同时用复阻抗的精确计算检查候选，不把近似边界当实测保证。

一个常见误判是把低频 L0 也固定成3.49 µH，再算允许自容。实际设计必须同时调整 L0 和 Cp，目标才是31 MHz的3.49 µH。

## 3. 原16匝×35 mm为什么不能直接采用

使用原25 mm导线中心直径、1 mm裸铜线：

| 量 | 审查值 |
|---|---:|
| Wheeler 低频几何电感 | 3.405 µH |
| 绕组长径比 | 1.4 |
| Medhurst 表估计绕组本体自容 | 约1.17 pF，不含端子和安装增加量 |
| 由此得到的31 MHz有效电感 | **约4.01 µH** |
| 第一自谐振估算 | 约79.7 MHz |
| 要让原L0恰好对应Leff=3.49所需自容 | 仅约0.188 pF，与本体经验估计明显不符 |

因此，原几何初值不是“SRF一定不达标”，而是**在合理自容下，31 MHz电抗已过大**。不能仅测得低频3.4 µH就认为已接近目标。按经验模型，拉长到约41 mm才接近不含安装增加电容时的目标。

自容依据为 Medhurst 原研究的 Cp=H·D（D以cm计，Cp以pF计），本次只对表内长径比插值。原文实验有指定支撑与端点接地边界；这里用于裸空心线圈是工程筛查，另外施加±20%自容压力，不称作本项目实测精度。[Medhurst，1947年3月，第84页表VI](https://g6yb.com/g3ynh/zdocs/refs/Medhurst/Med80-92.pdf)。其电阻研究也说明邻近效应和介质损耗需要单独考虑。[Medhurst，1947年2月](https://g6yb.com/g3ynh/zdocs/refs/Medhurst/Med35-43.pdf)。

## 4. 可制作的修订候选：16匝，约41～47 mm起调范围

保留1 mm线材和约25 mm中心直径，不必立即换大尺寸或买磁芯。下表将自容、有效电感、自谐振**联立**，每行都调到Leff(31 MHz)=3.48996 µH：

| 本体以外增加电容 | 所需轴向长 | 低频L0 | 总Cp | SRF估算 | 结论 |
|---:|---:|---:|---:|---:|---|
| 0 pF | 41.0 mm | 3.013 µH | 1.196 pF | 83.8 MHz | 理想简洁安装候选 |
| 0.5 pF | 44.1 mm | 2.844 µH | 1.715 pF | 72.1 MHz | 推荐作为**试制起点** |
| 1.0 pF | 47.2 mm | 2.694 µH | 2.233 pF | 64.9 MHz | SRF裕量较小 |
| 1.5 pF | 50.3 mm | 2.557 µH | 2.754 pF | **60.0 MHz** | 即使调到3.49 µH，仍不满足SRF门槛 |

表中额外电容是扫描变量，**0.5 pF不是已知的真实安装值**。建议机械上可调约40～50 mm，从约44 mm起调；在这个方向上压缩/拉伸时，同时复测Q和SRF，而不是只追电感读数。

14匝、约29～33 mm也有计算可行区；18匝需约56～64 mm才得到类似有效电感。故本次不再把18匝带多抽头作为首选结构，避免更多导线、支撑长度和开路尾匝。它们保留为计算比较，不另加采购。

**不要把“单个可调线圈覆盖2～5 µH”与“在3.49 µH调谐点满足三项指标”混淆。** 本轮只审查后者；原2～5 µH是仿真扫描范围，未证明一个实际线圈在整个范围都同时保持Q≥60、SRF≥62 MHz。

## 5. Q≥60是否有铜损基础

铜电导率5.8×10⁷ S/m、31 MHz，趋肤深度约11.87 µm。16匝、25 mm中心直径、总约20 mm引线的铜线长约1.277 m；用高频圆线表面电流近似，**单纯趋肤电阻约0.591 Ω**。此值不含邻近效应、焊点、涂层、支架介损、邻近金属涡流或线圈辐射，不能直接算成实物Q保证值。

为判断裕量，明确扫描假设：

- 邻近效应损耗倍率1/3/5；附加串联接触损耗0.1/1 Ω。
- 总有效并联电容损耗角正切0.001/0.02，作为介质/安装损耗压力量，并非PTFE或漆层实测属性。
- 本体经验自容倍率0.8/1.0/1.2；安装增加电容0/0.5/1/1.5 pF。
- 每个工况重新调轴长，使31 MHz有效电感仍为3.49 µH；精确求复阻抗及第一相位过零。共144组。

| 安装增加电容 | 压力网格最低Q | 最低SRF | 读法 |
|---:|---:|---:|---|
| 0 pF | 82.7 | 77.3 MHz | 在所设损耗压力内有共同余量 |
| 0.5 pF | 69.2 | 68.2 MHz | 在所设网格内仍满足，但不是制造保证 |
| 1.0 pF | 59.2 | 62.2 MHz | 已出现Q不达标 |
| 1.5 pF | 51.4 | 57.9 MHz | Q和SRF均可能不达标 |

**结论：铜线本身并未显示出Q≥60不可能；更紧的约束是安装总自容及其损耗。** 经验/压力模型包含未验证参数，不能把“网格通过比例”称为制造良率，也不能把模型中较高的Q直接写成器件规格。实际环境若有未计涡流、接触或介电损耗，Q可能低于此表。

本次没有重新搭建未经验证的线圈全波求解器，也没有把上一轮NEC的LD卡误当成线圈几何电磁模型。计算代码与全部假设在 `audit_coil.py` / `coupled_coil_results.json`。

## 6. 制造细节必须修正

1. **取消最终结构的闲置抽头和开路尾匝。** 首件直接绕16匝；若需要改匝数，重新端接并去掉尾段。不能先通过某抽头测试，再保留其余匝却仍引用独立16匝的计算。
2. 轴向长统一定义为第一匝至最后一匝的绕组占据长度；中心节距近似p=(l−d)/(N−1)。44 mm、16匝、裸线1 mm时p约2.87 mm；实际净间隙还应扣除漆层外径。
3. 线圈直径是**导线中心直径**。芯棒外径应约为25 mm减导线含漆外径；24 mm只是名义起点，漆层与回弹会改变成品尺寸，必须测量。可移除芯棒不必为RF低损耗而强制购买昂贵PTFE；留在线圈附近的端部支撑才需关注介损。
4. 端部使用非导电夹持；不保留穿心金属螺丝，不用金属螺杆调匝距，不用厚胶填满绕组。不声称这些措施能保证“增加电容≤0.5 pF”。
5. 推荐首件引线总长≤20 mm，两端短焊接/可靠端接；最终测量时使用实际支架和端子。板上大面积地、金属夹具、地网中心、探头都会改变端口自容和损耗，布局要固定记录。
6. 调整后锁定机械尺寸，再复测三指标；搬动、装壳或锁紧前后的数据不能混用。

## 7. 测量方案审查：原100/220 pF两点法不够

原电容仍可用于低频电感检查，但**不能承担“Cp≤2.52 pF”或“SRF≥62 MHz”的正式验收**。

反例：真实L0=3.000 µH、Cp=1.500 pF，假设频率测量完全无误差，仅100 pF与220 pF各有±1%公差。仍用标称电容代入两点法：

| 100pF误差 | 220pF误差 | 反算L0 | 反算Cp |
|---:|---:|---:|---:|
| −1% | +1% | 3.080 µH | **−2.110 pF** |
| +1% | −1% | 2.920 µH | **5.308 pF** |

可见电感只有几个百分点误差时，pF量级自容已经无法判定。换成更小外接电容可改善外推条件，但又更易受夹具影响；不能靠增购两只小电容就宣称问题解决。

现有设备记录只确认DS2102E、普通10×探头、型号未定的信号源，没有确认VNA/阻抗分析仪。`P2_天线阻抗实测规程.md`还明确：16 pF是示波器输入端参数，**不是已知的10×探头尖端电容**；本审查不重复该混淆。

采购前应先明确可借用的测量资源，而不是买齐材料后才发现无法验收：

- **首选借用/共享**能测31 MHz复阻抗且能扫至至少100 MHz的RF阻抗分析仪，或有合适串联夹具及校准能力的VNA；不在本任务内购买仪器。
- 在最终线圈端子参考面做校准/去嵌，扫频确认31 MHz的R、X和首次自谐振，并保留原始复数数据。仪器覆盖频率本身不代表在约680 Ω电抗、约11 Ω损耗处测量足够准确。
- Q=60时相位约89.045°，距90°只有约0.955°。简单示波器相位法对通道时延、探头负载很敏感；未经幅相校准不能给Q下保证。
- 100/220 pF低频谐振、直流电阻、弱耦合扫频可作辅助诊断；弱耦合测得的加载Q也不能未经耦合修正就当线圈端口Q。
- 必须保留实际支架/端子引起的影响，同时去除测量夹具额外影响；同一最终状态依次完成三项检查，不拿自由悬空SRF代替装后SRF。

厂家资料也强调工作频率、夹具与安装状态必须明确：[Coilcraft 工作频率测试](https://www.coilcraft.com/en-us/resources/application-notes/testing-inductors-at-application-frequencies/)、[SRF与夹具影响](https://www.coilcraft.com/en-us/resources/application-notes/measuring-self-resonant-frequency/)。

**最终状态：条件可制造，整套采购前审查暂不放行。** 这不是判定线圈做不出来，而是修订了不自洽的初值，并揭示了尚缺的测量能力。上一轮“可一次性备料”的表述应以本审查为准。线材等通用材料没有发现必须换规格的理由；但不能给供应商下单一个“16匝×35 mm、3.49 µH、Q≥60、SRF≥62 MHz已验证”的定制成品。

下一步只有一个技术闭环：按修订结构获得同一线圈组件的L(31 MHz)、Q(31 MHz)、首次SRF及其不确定度；如果只有计算而没有该证据，状态继续为待验证。上一轮理想L/R负载电流4.571 mA仍是条件仿真，不会因这份可制造性筛查自动升级为实际线圈性能。
