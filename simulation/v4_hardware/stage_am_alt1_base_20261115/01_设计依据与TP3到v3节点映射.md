# AM-ALT.1 续阶段设计依据与 TP3 到 v3 节点映射

日期：2026-11-15。范围：独立阶段 `stage_am_alt1_base_20261115`。此文件及本阶段结果优先用于解释本阶段工作，不改写历史记录。

## 1. 已确认的正式设计依据

来源：项目负责人在 AM-REQ.1 完成后的本次明确指令。作为本阶段设计约束登记，不虚构新增教师通知或批准文件。

1. 课程不要求发射端驱动50Ω。
2. 2.0/1.2Vpp不是正式发射端包络验收指标。
3. 检查对象v3是完整无线发射模块输出，不自动等于调制器输出TP3。
4. v3须满足指定AM波形与载波频率稳定性要求。
5. 发射机电池供电，整机功耗严格小于0.5W。
6. 必须无线接收，指定距离6m。保留原评分标准的v1/v2性能要求。

调制度、平台幅度、谐波等均量化报告，但不另造25%调制度、固定电压或50Ω通过门槛。原表3的频率扣分线仍按原文解释，不把内部筛查阈值写成课程条款。

## 2. 冻结链路及实际候选的对应

冻结链路：`vVCARRIER → TP2 → POLY调制器 → TP3 → eEPA → TP4 → eECHANNEL → ANT_RX → eERX → TP5 → RRF=50Ω → 检波/接收链`。

| 功能 | 冻结节点 | 本阶段候选真实元件节点 | 与课程v3关系 |
|---|---|---|---|
| 载波输入 | TP2 | C4晶振/缓冲/共射增益级末端`out` | 内部载波，不是v3 |
| 调制管 | POLY的功能位置 | `QM mc mb me 2N3904`；mc集电极、mb基极、me发射极 | 实际基极调制级 |
| 调制器交流输出 | TP3 | 新候选`mc → CMOUT(100pF) → tp3`，RTP3DC=1kΩ提供直流回路及低频抑制 | 内部观察点，不是最终验收端 |
| 后级隔离/驱动 | eEPA是理想占位 | `tp3 → CBUF(100pF) → ob`；`QOB vcc ob oe`，ROE=330Ω | 真实射随候选，有偏置、输入负载和供电电流；不宣称等效理想VCVS |
| 选频前接口 | 无独立冻结对应点 | `oe → COV3(10nF) → tx_drv` | 内部驱动点，不是加入选频网络后的v3 |
| 最终电输出测试接口 | 功能上最接近TP4 | `tx_drv → ROISO(1kΩ) → v3`；v3并联CTX=51pF及LTX=470nH串联损耗电阻 | 输出选频候选的最终连接器；完整发射机还需连接/验证实际天线及必要匹配 |
| 无线接口 | eECHANNEL | 本阶段尚未建立真实天线/传播/接收耦合 | 冻结0.1增益不能证明无线接收或6m |
| 接收侧50Ω | TP5到RF_OUT串联 | 不属于本阶段TX电路 | 与课程TX输出负载无关 |

**映射结论：冻结TP3是调制器输出，冻结TP4是发射后级输出的功能占位；课程v3应落在完整实际发射模块的最终输出接口。** 本阶段把新候选选频网络后的最终连接器命名为`v3`，这是可核查的工程映射，不是宣称教师原图直接指定了TP4。若之后再增加天线匹配网络，正式v3观察点必须位于该网络之后的最终天线馈电接口，当前连接器需重新命名为内部测点。

前期不带选频网络的`coupled_nom`、`coupled_hp_*`网表将COV3后的点称为v3，表示当时该候选的末端；它们保留用于对照，不是本表最新拓扑。`coupled_filter_*`才按本表映射。输出选频电感Q=40只是假设，ESR约2.29Ω；51pF电容加标称5pF测量负载共同参与谐振，不可忽略探头和天线电容。

目前的RTEST/CTEST只是可复现的实验室测量负载假设。既不视为课程规定，也不视为实测天线阻抗。不能以其上的好看波形代替完整无线验收。

## 4. 基极方案起点与两个调节量

旧`../stage_am_alt1/netlists/mod_B_base.cir`的`Q9M vcc m9col m9emit`实际把m9col作为基极，而m9base注入网络没有接到三极管基极，不能当有效基极调制试验。原件保留。

新方案：DC偏置RMT/RMB、基带注入RMINJ、射极直流负反馈RME，以及只在RF频率旁路的CME。基带直流耦合，避免串联基带耦合电容造成占空比相关基线漂移。基带并非理想无负载，最终要接实际LM393验证。

低频近似（暂忽略基极电流）：

`Vb ≈ (VCC/RMT + Vm/RMINJ)/(1/RMT + 1/RMB + 1/RMINJ)`。

`Ie ≈ (Vb−Vbe)/RME`只作工作区估计。RMT主要调静态点，RMINJ主要调注入幅度；二者仍通过总电导耦合，不能仅凭有两个旋钮宣称完全独立。通过二维扫描、固定低平台电流后的注入扫描验证能否补偿这种耦合，并检查Vcb/Vce、包络、实际源加载和功耗。
