**三个必须守住的判定边界：**

1. **末五周期 0.0447% 的“通过”是短窗假象，不作稳定性证明。** 窗口仅 200 μs：11.9058 mV/ms × 0.2 ms = 2.38 mV ≈ 实测跨度 2.15 mV，即该筛查测的是“窗口足够短”。缩短窗口总能通过。真正的判据是直接测漂移速率及其衰减。
2. **−0.7446 mV 是外推，不是实测。** 9 ms 内偏置从未停止上升。单指数全局拟合不成立（RMS 79 mV、外推渐近值 4.635 V 高于标称 4.496 V），是多指数收敛，只有局部行为被良好约束；投影基于局部 τ，对 τ 的敏感性：τ>约1.3 ms 才推翻“通过”，实测 8 窗均 ≤1.05 ms，结论稳健。要变实测需 12–14 ms（τ 的 3–5 倍）。
3. **口径**：“启动”指输出开始上升，约 **1.77 ms**；旧记录“约 6.5 ms 建立”来自普通样本平均，是另一口径。报告中必须写明所用定义。“7 ms 未通过 0.1%”应改述为**“7 ms 时仍处收敛尾部”**，不是“不收敛”。

**12 ms 与 TSTOP 上限（已定性为环境干扰）：** `COLD_12ms_tail`（`tran 1n 12m 11.5m 1n uic`，保存量与 9 ms 相同约 65 MB）74 s 报 `Internal simulation error`，推翻“保存量是触发条件”的假设；当时存在遗留 GUI Multisim 实例（PID 24344）干扰，杀掉后 20 ms 尾段跑 >4 min 无错（被中断，无完成证据）。`PROBE_rc_20ms`（3 元件 RC，无开关/宏模型）TSTOP=20 ms COMPLETED（6.24 s）→ **不存在全局 TSTOP 上限**。**受控重跑已成功**：`COLD_12ms_clean`（同一网表 sha256 `d6eff71d…`、同一 `tran` 卡，清场确认无其它 Multisim 实例）963.5 s 完成、`last_error` 为空、510,216 点、尾段 `.raw` 65.71 MB。故首次 12 ms 失败确系**环境干扰**，“9 ms 是硬上限”不成立，12 ms 可用。（注：`COLD_12ms_clean_status.json` 内 `raw_bytes=12815509` 是轮询首次检测到非空 `.raw` 时的瞬时快照，写入随后继续，最终以文件实际大小为准。）**分析已完成**（见第 3.3 节）：末五周期跨度 0.00379% PASS，与标称差实测 −1.2094 mV，9 ms 外推值 −0.7446 mV 已由实测取代。见 [12 ms定论报告](副本专用文件夹/cold12ms_20261014/冷启动12ms定论报告.md)、[TSTOP诊断与线性度设计](副本专用文件夹/final2_20261014/TSTOP诊断与线性度设计.md)。

```
τ = (11.75 − 8.75) ms / ln(11.9058 / 0.5743) = 3.0 / 3.0310 = 0.9896 ms
```

与 9 ms 报告八窗拟合的 **τ ≈ 1.005 ms 相差 1.54%**——**两条完全独立的证据链给出同一个 τ**，这是结果可信的核心。

**外推 → 实测的替换**：

| 时刻 | 状态 | 与标称差距 |
|---|---|---:|
| 9 ms | 实测 | −12.7150 mV |
| 9 ms | 外推预测（τ=1.005 ms） | −0.7497 mV |
| **12 ms** | **实测** | **−1.2094 mV（−0.02511%）** |
| 12 ms | 外推预测最终值 | −0.63 mV 左右（−0.013%） |

12 ms 实测与 9 ms 外推**方向一致、量级一致**（差 0.46 mV = 幅度的 0.0095%），外推没有落空。0.1% 阈值 = 4.8161 mV，当前差距 1.2094 mV **已在阈值内、余量 4.0 倍**；残余上升约 0.568 mV，预计最终 −0.64 mV（−0.013%）。τ 敏感性：即使 τ=1.5 ms（比两套证据都大 50%），最终差距也只有 −0.3479 mV，仍 PASS——**结论对 τ 不敏感**。

**局部指数拟合的局限（避免误读）**：全窗（2.5–12 ms）单指数拟合不成立（RMS 79.76 mV、V∞ 高于标称 84.9 mV），是多指数收敛；保存轨迹为三段（7 ms 尾 0.0202–6.9661、9 ms 尾 8.5663–8.9664、12 ms 尾 11.5667–11.9667 ms），完全落在空隙里的窗口会**静默退化成下一段**，故 `9.00–12.00`/`10.00–12.00`/`11.00–12.00`/`11.50–12.00` 四行是同一批数据、不是四次独立确认；该窗口 τ(1.003 ms) 是在比 τ 还短的窗口上拟合的，约束很弱——**速率衰减法不受此限制**，这也是两个方法都报的原因。尽管有这些局限，局部拟合 V∞ ≈ 4495.41–4495.46 mV（差距 −0.58 ~ −0.63 mV）与速率法预测的 −0.64 mV 高度一致，互为佐证。

**必须守住的边界**：

1. **12 ms 处偏置仍在上升**（0.5743 mV/ms）。**“12 ms 已完全稳定”不成立**；成立的是“差距已比 0.1% 阈值小约 4 倍，且速率证明它会继续收敛而非发散”。
2. **−0.63 mV 最终值仍是外推**（虽然 τ 有两条独立证据支持且结论对 τ 不敏感）。要变实测需再跑 15 ms 尾段（未测）。
3. **不得**据此宣称“9 ms 是硬上限”（已证伪），也**不得**宣称“任何 TSTOP 都能跑”（只证明 12 ms 在本电路本配置下可跑）。
4. **单次成功（n=1）**：对“是否存在 9–12 ms 积分上限”一次受控成功已足以判定不存在；但若要作“重复稳定性”陈述，建议再复现一次。
5. 11 份受保护源文件 sha256 已逐一核对，**全部 UNCHANGED（11/11）**。

**复现纪律**：运行前必须清场（`Get-Process -Name multisim | Stop-Process -Force`，清场前后均确认进程数为 0）；须用 32 位 PowerShell 驱动 COM；12 ms 约 16 分钟。见 [12 ms定论报告](副本专用文件夹/cold12ms_20261014/冷启动12ms定论报告.md) 第 9 节。

### 6.2 判定口径（写死，后续不得改）

1. **稳定性判据** = 0.1% 临时重复性筛查（项目自定，**非任务书容差**）：末尾至少 5 个完整周期中，V2 周期均值跨度、robust_vpp 跨度分别 ≤ 末尾平均 robust_vpp 的 0.1%，周期时长相对跨度 ≤0.1%。**同时必须报告漂移速率及其趋势**——末五周期筛查单独不构成任意窗长下的稳定性证明（窗口缩短总能通过，9 ms 报告第 3 节已证）。
2. **测量方法** = `measure_stage3.py` 全套：`crossings` 交点、2 ns 均匀插值、robust 幅度 P98−P2、**时间加权均值（梯形积分）而非样本普通平均**、剔除不完整周期。所有窗口基于**实际返回时间轴**（TSTART 首点取跨阈值后第一个自然步点，约 +1 ns）。
3. **启动时刻** = 输出 V(v2) 开始上升，约 **1.77 ms**。旧"约 6.5 ms 建立"来自普通样本平均，属另一口径，不再使用；4.218 ms 则是"最后一次低于 1 V"的电平交越事件，两者都不是稳定时间。
4. **收敛完成度** = 与已验收预充电标称（4.496041 V）的差距。当前差距 −1.2094 mV（−0.0251%）**未归零**；预计最终 −0.64 mV（−0.013%）为**外推**。
5. **线性误差** = 归一化增益 − 1，其中归一化增益 = (Vout/Vin)@2Vpp ÷ (Vout/Vin)@4Vpp；等价于 |Y − X/2|/(X/2)（与指标文件第 131 行约定一致）。当前 −1.4435%。
6. **证据入口分列**：COM 驱动 ≠ 命令行引擎 ≠ 原生 GUI 点击，各自适用范围不得互替（01 第 5 节原则 5）。

### 6.3 保留边界（验收结论的组成部分，引用本结论时须一并带上）

1. **不写"已完全稳定"**。12 ms 处偏置仍以 0.5743 mV/ms 上升；成立的是"差距在 0.1% 阈值内（余量 4 倍）且速率证明继续收敛"。
2. **最终值 −0.64 mV（−0.013%）仍是外推**。要变实测需 15 ms 尾段（未测）。结论对 τ 不敏感（τ=1.5 ms 时仅 −0.3479 mV，仍 PASS），但外推身份须如实标注。
3. **reltol=1e-4 下 GUI 冷启动仍然失败**（止于 225.797635 ns，四次运行均死在第 7 载波周期 ±11 ps）。这是**已定位、可复现、未消除**的求解器入口限制，不是已修复的缺陷；S03-04 的通过依赖 1e-3/7（SPICE 默认、与引擎及历史验收数据同容差）。GUI 侧历史数据是混合容差（预充电 2 ms 跑在 1e-4 上），**不得笼统写"GUI 与引擎设置一致"**。
4. **12 ms 成功为 n=1**。判"9–12 ms 无积分上限"一次受控成功已足够（唯一变量是环境，输入逐字节相同）；但"重复稳定性"陈述需再复现。
5. **225.806 ns 事件的元件级归属未证实**（`_S1/_S2` 10 mV 阈值带交越为假设，需针对性运行才能定位到具体元件）。不影响以上任何判定。
6. **2 Vpp 只测 D=50% 一档**；1 Vpp/3 Vpp 未测；机理未定位（幅度缩小比一半略多、直流偏置几乎不动，与固定压降/开关阈值方向一致，仅为描述非结论）。
7. **0.1% 是工程筛查判据，不是评分指标**。最终报告应写"稳定性判定"，不得写成"指标不合格/合格"。
