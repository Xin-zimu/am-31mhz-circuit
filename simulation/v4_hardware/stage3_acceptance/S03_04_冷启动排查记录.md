## 2. 原生 GUI 20 μs 复现：失败 → 根因 → 成功

**失败运行（reltol=1e-4/trtol=1，TSTEP=TMAX=1 ns）：**

- 输入副本与 COM 成功矩阵 `V_1n_1n.ms14` 完全同哈希：`10b971880847cbfb2c9d0b3e5c780c7856ba200998aa53d8e4ca8d4e69a5ac73`。

- 原生GUI点击Run后，报 `Unable to converge during transient analysis`、`Simulation canceled`。
- `.gra` 实际终点 `2.257976350349652e-7 s`；一页、页标题对应本轮工程、四条曲线各563点。不能把横轴20 μs刻度当成已计算到20 μs。
- 首个正时间10 ps：V(bb_in)=14.112384 μV、V(v2)=6.136117 μV、V(bbo)=81.397 mV，未复现4.5 V预充电起点。
- [失败波形](副本专用文件夹/gui_evidence_20261014/S03_GUI_COLD_20us.gra)、[参数截图](副本专用文件夹/gui_evidence_20261014/01_20us_parameters.png)、[失败截图](副本专用文件夹/gui_evidence_20261014/04_20us_gui_failure.png)、[实际网表](副本专用文件夹/gui_evidence_20261014/S03_GUI_COLD_20us_actual.cir)、[审计JSON](副本专用文件夹/gui_evidence_20261014/gui_20us_audit.json)。

**根因（只读诊断，未启动仿真器）：**

- 四次 GUI 冷启动运行（trap/gear、2 ns/1 ns、zero_ic/UIC）全部止于 225.7955~225.7984 ns = **第 7 个载波周期 ±11 ps**（31 MHz 周期 32.258065 ns）；ITL4 由 100 提到 500 只把存活时间延长 4.3 倍，是迭代预算耗尽而非硬墙。
- 引擎在同一网表 20 μs 全程只有两次步长骤降：启动处与 **225.80095 ns**——该时刻是电路固有的收敛危机（V(bbo) 导数跳升 50 倍），引擎须把步长从 1008 ps 砍到 1.2095 ps 才能跨过。
- 决定性差异是步长控制松紧：GUI（1e-4/1）步长中位数 307.037 ps、仅 11.74% 达上限、事件处最深 0.0116 ps；引擎（默认 1e-3/7）中位数 1008.065 ps、68.50% 达上限、最深 1.2095 ps。GUI 末 11 步从 5.8 ps 磨到 0.012 ps 而解几乎冻结（V(bb_in) 位移 69.6 μV），是单点牛顿不收敛，不是内存不足。
- 由此**撤回**两条旧结论：①“TSTEP=TMAX=1 ns 解除根因”——GUI 在 1/1 ns 下仍死于同一时刻，该“修复”只在 COM/引擎路径验证过；②“控制行差集为空 ⇒ 有效设置一致”——引擎根本不执行 `.options`。225.806 ns 事件的具体元件归属（`_S1/_S2` 10 mV 阈值带交越）仍是**未证实假设**。见[诊断报告](副本专用文件夹/gui_diagnosis_20261014/GUI失败原因诊断报告.md)。

**成功运行（仅改 RELTOL=1e-3、TRTOL=7，其余不变）：**

- 同一工程文件 `S03_GUI_COLD_20us.ms14`，TSTEP=TMAX=1 ns、TSTOP=20 μs、UIC 零初值全部不变，与失败运行构成单变量对照。

## 3. 冷启动长窗的正确判定

2 ms窗口不足以认定不能启动。5 ms输出已建立，4.218 ms是最后一次低于1 V的电平事件；不是稳定时间。7 ms完整数据有7,127,505点，沿用原S03方法重算末五完整周期：

| 指标 | 冷启动7 ms | 预充电标称5 ms |
|---|---:|---:|
| V2 robust幅度 | 4.814008 Vpp | 4.816023 Vpp |
| 时间加权均值 | 4.417497 V | 4.496041 V |
| 周期均值跨度 | 15.372227 mV | 0.350986 mV |
| 均值跨度/幅度 | 0.319323% | 0.007288% |
| 0.1%临时重复性筛查 | 未通过 | 通过 |

原 `cold7ms_analysis.py` 使用样本普通平均。“6.5 ms已稳定”“收敛到标称”“S03-04通过”均撤回。均值进入标称2%范围不能替代原0.1%重复性筛查。[加权逐周期数据](副本专用文件夹/gui_evidence_20261014/weighted_7ms_review.json)是当前测量依据，旧分析和图仅作历史材料。

7 ms引擎成功、10 ms报 `Internal simulation error` 仅限定已测结果；不认定7 ms为上限，也不认定10 ms必然受内存限制。9 ms 尾段已跑通（见下），填补了 7–10 ms 之间的空白；12 ms 尾段失败但归因未定（见第 3.1 节）。

### 3.1 9 ms 尾段：稳定性可判定为“外推收敛”（2026-10-14 新增）

`cold9ms_20261014/COLD_9ms_tail`：`tran 1n 9m 8.5m 1n uic`，COMPLETED，646 s，510,205 点，65.71 MB；网表与 7 ms 同源（sha256 `d6eff71d…`），`.raw` sha256 `54eb259e…`。中位步长 1000.000 ps、最小 16.15 ps。

| 指标 | 9 ms 尾段（8.5–9.0 ms） |
|---|---:|
| V2 robust 幅度 | 4.816122 Vpp |
| V2 时间加权均值 | 4.484541 V |
| 周期均值跨度 | 2.154607 mV |
| 跨度/幅度 | 0.044737%（名义通过 0.1%） |
| 9 ms 时与已验收标称差距 | −12.7150 mV（−0.2640%） |
| 漂移速率 | 11.9058 mV/ms，仍在单调上升 |
| 局部 τ | ≈1.005 ms（8 个连续 0.5 ms 滑窗均在 0.99–1.05） |
| 投影最终差距 | **−0.7446 mV（−0.0155%）→ 投影通过** |

**三个必须守住的判定边界：**

1. **末五周期 0.0447% 的“通过”是短窗假象，不作稳定性证明。** 窗口仅 200 μs：11.9058 mV/ms × 0.2 ms = 2.38 mV ≈ 实测跨度 2.15 mV，即该筛查测的是“窗口足够短”。缩短窗口总能通过。真正的判据是直接测漂移速率及其衰减。
2. **−0.7446 mV 是外推，不是实测。** 9 ms 内偏置从未停止上升。单指数全局拟合不成立（RMS 79 mV、外推渐近值 4.635 V 高于标称 4.496 V），是多指数收敛，只有局部行为被良好约束；投影基于局部 τ，对 τ 的敏感性：τ>约1.3 ms 才推翻“通过”，实测 8 窗均 ≤1.05 ms，结论稳健。要变实测需 12–14 ms（τ 的 3–5 倍）。
3. **口径**：“启动”指输出开始上升，约 **1.77 ms**；旧记录“约 6.5 ms 建立”来自普通样本平均，是另一口径。报告中必须写明所用定义。“7 ms 未通过 0.1%”应改述为**“7 ms 时仍处收敛尾部”**，不是“不收敛”。

**12 ms 与 TSTOP 上限（归因未定）：** `COLD_12ms_tail`（`tran 1n 12m 11.5m 1n uic`，保存量与 9 ms 相同约 65 MB）74 s 报 `Internal simulation error`，推翻“保存量是触发条件”的假设；但当时存在遗留 GUI Multisim 实例（PID 24344）干扰，杀掉后 20 ms 尾段跑 >4 min 无错（被中断，无完成证据）。`PROBE_rc_20ms`（3 元件 RC，无开关/宏模型）TSTOP=20 ms COMPLETED（6.24 s）→ **不存在全局 TSTOP 上限**。故既不能称“9 ms 是硬上限”，也不能称“12 ms 可用”；`COLD_12ms_clean` 受控重跑待定，若仍失败则接受“9 ms + 外推收敛”并如实记录。见 [TSTOP诊断与线性度设计](副本专用文件夹/final2_20261014/TSTOP诊断与线性度设计.md)。

详见 [冷启动9 ms稳定性报告](副本专用文件夹/cold9ms_20261014/冷启动9ms稳定性报告.md)（方法全程复用 `measure_stage3.py` 的 `crossings`、2 ns 均匀插值、P98−P2、梯形时间积分均值，与 7 ms 加权重算完全同方法，可直接比较）。
