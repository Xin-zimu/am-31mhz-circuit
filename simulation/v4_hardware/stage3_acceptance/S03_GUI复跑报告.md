# S03-03 原生 GUI 复跑记录

日期：2026-10-12。结论：按用户放宽时长后的范围，**2 ms 原生 GUI 复跑通过**。已另存工作副本、保存并重开、从分析对话框运行，随后在 Grapher 保存原始 `.gra`。基线没有覆盖。

## 时间窗与失败记录

首先尝试了 5 ms，只有四个输出节点，TSTEP/TMAX 均为 2 ns。在界面显示约 3.469 ms 时出现内存不足，未完成、未保存为通过的波形，详见 `gui_attempt1_failure.json`。

用户随后明确表示“不一定要 5 ms 这么严苛”。改用 2 ms，仍保留相同时间步长与精度设置，以末尾完整周期的重复性与同时间窗引擎结果判断，不再把 5 ms 作为 GUI 复跑的必备时长。已有 5 ms 引擎结果继续作为独立证据。
