## 6. 已解决的问题

新增S03-03原生证据：[2 ms GUI复跑报告](../simulation/v4_hardware/stage3_acceptance/S03_GUI复跑报告.md)。输出频率19,998.043 Hz、占空比50.22635%、robust幅度4.813213 Vpp、时间加权均值4.505373 V；与引擎前2 ms相比，幅度差约0.068%、均值差约0.866 mV。原始 `.gra` 每曲线3,063,221点，终点2 ms，末尾五周期重复性筛查通过。仍是预充电状态，冷启动结论另记。

| 问题 | 结论 |
|---|---|
| “运放增益只有 1” | 前次确认是观察了输入两端网络；不能把 V(n) 当作引脚号 |
| BBO 约 3.85 V 平线 | 本次确认实际输出悬空，修复文件内部端点结构后恢复 |
| “OPAx197 在本机不能做瞬态” | 已排除为本次平线原因；保留原模型即可得到正常瞬态输出 |
| 修改后能否保存、重开 | 最终基线已经过原生保存及重新载入检查 |
| 冷启动“无法收敛” | 控制行差集为空：GUI 工程与引擎成功运行在 TSTEP/TSTOP/TSTART/TMAX/IC 及全部启用选项上逐项一致（实际生效上限同为 1.00806 ns）。原生 GUI 单变量矩阵（各重复 2 次）：只有 `TSTEP` 与 `TMAX` **同时为 1 ns** 才通过 5.1 µs，任一为 2 ns 即停在 **225 ns**。把副本的 TSTEP=TMAX 设为 1 ns 后，同一工程、同一选项跑满 20 µs 与 2 ms。注意：同网表同上限下命令行引擎**不**失败，故上限数值不足以解释全部现象，GUI 与引擎的差异机理未定位 |
| 冷启动“没有启动” | 该判断来自 2 ms 窗口，**不成立**。零初值冷启动确实启动并收敛：5 ms 时 V(v2) 已于 4.218 ms 稳定输出；**7 ms 运行（7,127,505 点）末段 0.5 ms 收敛到预充电标称**，V(v2) 均值 4.4492 V vs 标称 4.5322 V（−83 mV），V(bb_in) 4.4978 V vs 4.5028 V（−5 mV）。10 ms 会触发 `Internal simulation error`，7 ms 是可用较长窗口 |
| “引擎用了另一套 reltol/trtol” | 已被否证。引擎命令行的 `set` 与 `option` 对求解器无效：任意组合/写法/位置下 `.raw` 数值逐位相同；`option` 直接报 XSPICE 不支持。历史上 GUI 与引擎的数值差异不能归因于求解选项 |

详细过程见 [全程排查复盘](../simulation/v4_hardware/AM_OPA197_全程排查复盘.md) 与 [S03-04 冷启动排查记录](../simulation/v4_hardware/stage3_acceptance/S03_04_冷启动排查记录.md)。
