## 4. 线性误差定义与数值

**定义**（报告引用时必须写明）：

```
归一化增益 = (Vout / Vin) / (Vout / Vin)@4Vpp
线性误差   = 归一化增益 − 1
```

| 用例 | Vin (Vpp) | Vout (Vpp) | 增益 | 归一化增益 | 线性误差 |
|---|---:|---:|---:|---:|---:|
| 4 Vpp | 4.000003 | 4.816023 | 1.20400 | 1.00000 | 0 |
| **2 Vpp** | 2.000001 | 2.373252 | 1.18663 | **0.98557** | **−1.4435%** |

因输入恰为一半，两种等价表述给出同一数值：
- 归一化增益变化：**−1.4435%**
- 输出幅度相对"精确一半"的偏差：`2.373252 / 2.408011 − 1` = **−1.4435%**（−34.76 mV）

## 5. 观察到的物理特征

从波形看（见 `linearity_2vpp.png` 左上）：

- 输出是方波，**高/低电平相对均值对称**：4 Vpp 时 +2.40 / −2.40 V；2 Vpp 时 +1.19 / −1.19 V。
- **直流偏置几乎不动**（均值 4.496 → 4.485 V，−10.7 mV）。
- 幅度缩小得**比一半略多** → 增益在中低幅度处轻微下降。

这与解调器中存在固定压降/开关阈值的行为方向一致（幅度越小，固定项占比越大）。**但本次没有做机理定位，这只是与数据一致的描述，不是已证明的结论。**
