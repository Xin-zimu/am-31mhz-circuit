# TSTOP 上限诊断 + 线性度测试设计（2026-10-14 补充）

## 1. 12 ms 失败了，但原因不是"积分上限"

### 事实

| 运行 | 命令 | 结果 | 用时 |
|---|---|---|---|
| 7 ms 全窗 | `tran 1n 7m 0 1n uic` | 成功，7,127,505 点 | 9.5 min |
| **9 ms 尾段** | `tran 1n 9m 8.5m 1n uic` | **成功**，510,205 点（保存） | 10.8 min |
| 10 ms 全窗（归档） | `tran 1n 10m 0 1n uic` | `Internal simulation error.` | 2 min |
| **12 ms 尾段** | `tran 1n 12m 11.5m 1n uic` | **`Internal simulation error.`** | **74 s** |
| **20 ms 尾段** | `tran 1n 20m 19.5m 1n uic` | 跑到 >4 min 无错（被中断，未完成） | — |

### 关键推理

我原来的假设是"10 ms 的失败是保存量（10e6 点 ≈ 1.3 GB）限制，TSTART 尾段能规避"。**这个假设被 12 ms 的失败推翻了** —— 12 ms 尾段和 9 ms 尾段保存量相同（各 0.5e6 点 ≈ 65 MB），一个失败一个成功。

但我又发现了一个**混淆变量**：12 ms 失败时（74 s），一个**遗留的 GUI Multisim 实例**（PID 24344，打开着 `S03_GUI_COLD_20us`）仍在运行。杀掉它之后，20 ms 尾段跑了 **>4 分钟无错**（远超 12 ms 失败的 74 s）。

因此：

- **保存量不是触发条件**（9 ms 与 12 ms 保存量相同）。
- **`Internal simulation error.` 不是对 TSTOP 的立即拒绝** —— 20 ms 尾段跑了 4+ 分钟。
- **遗留实例干扰是一个成立的假设**，但尚未被受控实验证实（20 ms 那次被中断，未取得完成/失败证据）。

### 已确定的廉价事实（`PROBE_rc_20ms`）

3 元件 RC 电路（V1/R1/C1，无开关、无宏模型）在 **TSTOP=20 ms** 下：

```
status       = COMPLETED
wall_seconds = 6.24
raw_bytes    = 1,119,717
```

**→ 不存在全局性的 TSTOP 上限。** 20 ms 对简单电路完全可行。

## 3. 2 Vpp 线性度：改用 TSTART 尾段

原计划 `tran 2n 5m 0 2n uic`（全窗保存约 630 MB）存在与 10 ms 类似的内存风险。**改为尾段**：

```powershell
-Tag LIN_2Vpp_tail     # tran 2n 5m 4.5m 2n uic
-Tag REF_4Vpp_tail     # 同上，4 Vpp 参照
```

**为什么这样安全**：TSTART 只限制**保存**什么，积分仍从 t=0 开始、步进完全一致 —— 这一点已在 `engine_acceptance_20261014/compare_tstart.py` 中**逐位验证**（重叠窗内时间轴与四个变量最大绝对差 `0.000000e+00`，最小步长也相同）。因此末尾五周期的测量结果**不受影响**，而 `.raw` 从约 630 MB 降到约 63 MB。

**两个用例的差别只在输入衰减分压器**（D=50% 行）：

| 用例 | rRVAT | rRVAB | 预充电 |
|---|---|---|---|
| `REF_4Vpp_tail` | 1847.93 Ω | 18152.1 Ω | C111=0.43 V, C115=−4.1 V, CBB=4.5 V |
| `LIN_2Vpp_tail` | **10905.544559 Ω** | **9094.455441 Ω** | 同上 |

接收链 `rRG_BB / rRF_BB / rRV_BB / rRLOAD` 逐字节不变（脚本已断言）。`rRVRF / rRVDT / rRVDB` 不变。

**为什么用预充电而不是冷启动**：4 Vpp 的对照基准是**已验收的 S03-03 预充电标称**。冷启动会把"建立时间"与"幅度线性度"两个变量混淆。

**为什么两个都跑**：`REF_4Vpp_tail` 本身不改结论，但它证明"2 Vpp 与 4 Vpp 是在同一求解配置、同一方法下测的"，排除步长差异（本用例请求 2 ns，实际生效 1.0080645 ns）带来的疑点。

### 判定口径

对两个用例各取**末尾五个完整周期**，使用既有 `measure_stage3.py` 方法（2 ns 均匀插值、P98−P2 robust 幅度、梯形时间加权均值），报告：

| 量 | 4 Vpp（已验收基准） | 2 Vpp（本次） |
|---|---|---|
| V2 robust 幅度 | 4.816023 Vpp | 期望约 **2.408 Vpp** |
| 输出频率 | 19,998.043 Hz | 应基本不变 |
| 占空比 | 50.22635% | 应基本不变 |
| V2 时间加权均值 | 4.496041 V | 关注是否随幅度变 |
| 归一化增益 | 1.0000（定义基准） | 输出幅度 / 输入幅度 |

**线性误差的定义必须在报告中写明**（例如：相对 4 Vpp 的归一化增益变化百分比），不能只写"线性良好"。
