# S05-06 附加勘误：RF 电压增益单位

日期：2026-10-30。在 S05-07 读取归档时发现。**不覆盖 S05-06 原报告、脚本、CSV、raw 或哈希记录；本文件与修正副本一起使用。**

## 错误与范围

S05-06 §7 表头“31M 增益/dB”及该节文字把线性电压增益误标为 dB；`gain_20261030/network_sensitivity.csv` 的 `g31_dB` 列有同一问题。生成原因是 `make_measurements.py` 直接把 `c['g31']` 写入该列，`write_report.py` 也沿用了 dB 表头。`g31` 实为 AC 1 V 开路源对应的 `abs(v(rf))`，单位 **V/V**。

| 条件 | 原始线性电压增益 / V/V | 正确 dB 值，20log10(G) |
|---|---:|---:|
| Q20 | 20.9578 | 26.4269 |
| Q40 | 35.1854 | 30.9272 |
| Q50 | 39.2843 | 31.8844 |
| Q80 | 46.3630 | 33.3234 |
| 源阻抗 200 Ω | 20.9884 | 26.4396 |

以 [修正数据副本](lc_realization_20261030/s0506_network_units_corrected.csv) 的完整精度为准；该副本直接从历史结果 JSON 的 `metrics.g31` 换算，同时提供 `gain31_v_v`、`gain31_db` 两列。

Q20→80 对应 **26.43→33.32 dB，变化约 6.90 dB**，不是增大 25.40 dB。Q40 相对 Q50 损失约 0.96 dB。原来“Q 对增益显著敏感”的判断仍成立，但影响量应使用正确单位。

未受此错误影响：相对 29/33 MHz 抑制（本来已按比值取对数）、阻塞的 20 kHz 基波变化、带宽、输入阻抗、回波损耗、最终基带 Vpp 与削底判定。原元件响应图使用 `20*log10(abs(v(rf)))`，其 dB 纵轴正确。**没有因此重跑任何历史仿真。**

README 与项目管理 02/03 的当前摘要同步修正单位，并链接本勘误。原归档的其他限制继续有效。
