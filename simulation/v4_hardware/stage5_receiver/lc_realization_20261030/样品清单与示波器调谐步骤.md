# S05-07：少量样品清单与示波器调谐步骤

日期：2026-10-30。对应 [S05-07 报告](../S05_07_LC实物化与调谐验证.md)。用户目前尚未采购、可用设备为示波器。

**这份清单可用于准备独立选频前端的少量验证样品，不能当作已验收整机的最终 BOM。** 原 A+G22 主网表和 Q1/Q2 保留；本轮夹具改变的是 LC 元件落地方式。厂家在其他频率给出的 Q 不自动等于31 MHz的保证值。尚未核对具体销售渠道库存或含运费价格，按完整料号少量询价即可，不购买整盘或套装。

## 2. 连接与初调值

```text
50Ω测试源 ─ CSEL 15p ─ tank1 ─ CK 2.4p ─ tank2 ─ COUT 11p ─ 原Q1输入
                         │                 │                    │
                    460nH 到地        460nH 到地               1MΩ到地
                         │                 │
                 (30p ∥ 微调)到地  (39p ∥ 微调)到地
```

两腔电感和调谐电容分别并联到地。微调转子端按厂家端子图接地，先确认针脚而不是按外观猜。建议总CT初设约40.4/46.3 pF；没有电容表时这些是搜索起点，不应把旋钮转角直接当线性pF标尺。

软件角点所需CT1=35.39～44.80 pF、CT2=42.58～50.20 pF，均在建议组合范围内。这是有限模型角点的覆盖，不是任意布线都能调回来的保证。优先保持CSEL/COUT/CK不变，先调两只CT；只有明确发现加载带宽问题时才换CK，控制变量。

## 3. 只有示波器时的实际测试条件

示波器可测幅度/频率，但自身一般不产生29～33 MHz可控激励。**需借用实验室射频信号源**，或确认现有设备的信号发生输出覆盖该频段。这里不调用真实TX作激励，不把下一阶段联调提前。尚未知道示波器带宽、探头电容和信号源能力，开测前记入记录表。

RF测量建议使用足够带宽的示波器（例如100 MHz或以上作为实验准备目标），并确认31 MHz幅度误差；有限带宽设备可作相对调谐，但不能不校准就作绝对幅度验收。使用短接地弹簧，避免长鳄鱼夹地线。

**不要把普通无源探头直接接tank1/tank2调谐**：本轮仅额外10 pF就足以把加载中心移到29.59 MHz。优先测射随缓冲后的RF点。该点也有探头负载，应记录其R/C并保持各频点连接一致；当前仿真的2 kΩ∥10 pF测试负载与实际探头不一定相同，必要时按实际R/C另建短AC对照。不要把示波器50 Ω输入直接挂RF点，除非明确验证该负载。

没有VNA时不把回波损耗、VSWR、线圈Q或SRF写成“实测”。可以先用固定50 Ω激励验证加载传输响应；这能确认前端是否达到测试目标，但不能单独识别每只线圈的Q。真实天线匹配仍需后续测量或有证据的调整。

## 4. 调谐流程

1. **固定版本和负载**：记录两只电感完整料号/批次、CSEL/COUT/CK、CT固定段、供电、探头R/C和测点。保持原Q1/Q2，先检查其直流工作点。
2. **确认源幅度口径**：信号源50 Ω显示值常按匹配负载定义，本项目Ac按开路峰值定义。先用已知负载校核，记录实测值；不要把dBm、Vpp、开路峰值混用。
3. **低电平CW初调**：例如开路峰值约1 mV作为起点（不是正式验收激励），从RF点观察28～34 MHz响应；比较时校核源在各频点的幅度。输入减半时RF幅度应接近减半，先确认未进入明显压缩。
4. **两只CT交替小调**：目标是加载通带覆盖31 MHz、两边衰减接近设计；记录29/31/33 MHz和3 dB边界。不要只在31 MHz追求最高幅度，也不要把双峰之一等同通带中心。通过更换固定C先接近目标，再少量微调，避免超过微调器件的机械寿命。
5. **复查耦合**：若带宽过宽或过窄，先排查两线圈意外互感、焊接互容和探头影响；再决定是否换CK备选值。更改布局或CK后重新测全部频点，保留修改前结果。
6. **记录可比的三个指标**：G31、29/33相对响应、3 dB带宽同时报告。约31 MHz中心/约2 MHz带宽/两侧约12 dB抑制是历史候选的参考，不是新创课程扣分门槛。若幅度明显偏低，不能仅因中心调回就放行。
7. **之后才接检波与G22复验**：当元件和调谐状态固定后，再做10 mV输入、10/50%方波与阻塞测试；正式整机还需30%和比例测试。当前AC数据不直接给出最终Vpp，旧40～60 mV边界不能自动移植到新元件。
