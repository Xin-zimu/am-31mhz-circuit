## 2. 测量系统校验

用户本轮确认示波器为 **RIGOL DS2102E**。[官方资料](https://beyondmeasure.rigoltech.com/acton/attachment/1579/f-0790/1/-/-/-/DS2000E_DataSheet_EN.pdf)列明：100 MHz、双通道最高各 1 GSa/s，输入可选 **1 MΩ∥(16±3) pF 或 50 Ω**，有 20 MHz 带宽限制。原厂标配 PVP2350，但**用户当前探头型号尚未确认**，不得按标配推定。

| 项目 | 准备要求 | 当前状态 |
|---|---|---|
| DS2102E | 预热≥30分钟；关闭20 MHz限带；先用DC耦合、正常采样；保持通道/量程/探头倍率一致；记录实际采样率 | 型号已确认，现场设置待执行 |
| RF信号源 | CW正弦至少覆盖28～34 MHz，最好20～44 MHz；标称50 Ω；支持10 kHz或更细步进及幅度调节 | 可借性、型号未确认；示波器校准方波不能替代它 |
| 低电容探头 | 尖端总输入1～3 pF；核对输入电阻、线性范围、供电、输出接口与DS2102E兼容性 | 待借；不能只看“有源/高带宽”名称 |
| 无源探头 | 核对型号、10×档实际尖端电容；补偿后使用短地弹簧 | 型号待查；不直接接tank验收 |
| 端接/同轴 | 同轴直送DS2102E时选内置50 Ω；若用外置贯通50 Ω，示波器选1 MΩ | 禁止内外50 Ω同时并接成25 Ω；探头按其手册选择终端 |
| 电源/辅助 | 9 V可调限流电源；万用表借用作断电短路和上电极性核对 | 库存待查；独立无源LC本身不接9 V |

- [ ] 在 LC 入口连接平面，用信号源→同轴→50 Ω终端校准 28～34 MHz；记录每点端接电压、量程、通道及附件。信号源标注“into 50 Ω”的幅度与开路电压相差约2倍，必须注明口径。
- [ ] 探头路线在这个已知低阻校准点核对29/31/33 MHz幅度；缓冲路线先做自身直通扫频。普通低频探头补偿不能替代31 MHz幅度校准。
- [ ] 接DUT时保留信号源本身50 Ω源阻抗；**不因“需要50 Ω”在LC入口另并一个50 Ω**。校准用的端接要按接线图移走。长同轴、接头和失配带来的频率变化也须纳入误差，必要时在入口前用已校准的衰减垫改善源端回波。
- [ ] 独立LC先用开路源 **10 mV峰值 CW**；若读数接近噪声底，可在独立无源夹具中提高幅度并复核线性。不要把该幅度沿用到之后的有源接收链。

## 3. 独立 LC 制作

```text
RF源(内部50Ω) ─ CSEL15p ─ tank1 ─ CK2.4p ─ tank2 ─ COUT11p ─ port
                           │                 │                  │
                   L1 || (30p+CT1)   L2 || (39p+CT2)    RPORT1M + 可拆测量夹具
                           └──────── 短公共地 ────────────────┘
```

**port 是 COUT 后、原 CIN1/Q1 前的节点，不是 tank2，也不是已有射随输出 rf。** 真实接收机由 Q1 输入形成复数负载，独立板不能开路或改成50 Ω就套用原曲线。本轮给出的可拆夹具是 **953 Ω电阻 + 总约14 pF**，总电容包含补偿电容、探头/缓冲输入及连接寄生。[接口校核](s05_10_measurement_20261030/接口校核与勘误.md)给出适用边界。

- [ ] 先做公共地、入口/输出接口和可拆负载焊盘；检查桥连，再装固定电容、两只微调、最后装线圈。
- [ ] 两只线圈轴向先近似正交并留出调整空间；输入与输出分开走，CK短接。短引线、短回流优先；不用固定“架高5 mm”规则，也不声称某个间距保证某个互感k。
- [ ] 记录线圈间距、轴向、高度、地铜位置并拍照。金属工具、探头线、手、地铜靠近线圈都会改变结果；测量时保持位置一致，调完移开工具再读数。
- [ ] 微调电容量的模型起点约CT1=10.61 pF、CT2=7.15 pF；没有电容测量时只能以中间机械位置起步，不能把角度当成准确电容量。
- [ ] 不额外安装网表中的RLOSS/CSELF/CBOARD：它们表示损耗和寄生，不是采购元件。不要拉伸线圈“粗调”后还沿用原460 nH规格。

## 4. 加载扫频：两条路线

| 路线 | 接法 | 使用条件 |
|---|---|---|
| **A：借到低电容探头** | port→探头；port同时接953 Ω与CEXT；RPORT保留。使 **CEXT+C探头+C连接≈14 pF** | 按实际尖端R/C和探头输出校准。1 pF探头也不直接接tank作为原设计验收 |
| **B：借不到，使用受控缓冲** | port→短输入测试缓冲→串联49.9 Ω→隔直→50 Ω同轴→DS2102E内置50 Ω；port仍有953 Ω与补偿电容 | 候选为ADA4817-1单位增益小板；先验证加载、平坦度及稳定性，再连LC。电路与放行步骤见[接口说明](s05_10_measurement_20261030/接口校核与勘误.md)；**目前尚未通过缓冲器实物资格** |

受控缓冲的典型输入电容不能直接视为整块小板电容。本轮仅验证了接口的R/C预算，未用理想缓冲结果宣布具体器件通过。若两条路线暂时都不具备，仍可备料、做独立LC和校准夹具；定量扫频等测量链满足条件后再做。以后已有RF级时，普通探头测rf是另一种可校准路线，但本轮不为此提前搭完整接收机。

操作顺序：

1. 固定测量夹具与线圈位置，在28～34 MHz以100 kHz步进粗扫；若峰/边界不在范围内，再扩展至20～44 MHz。记录原始幅度及校准值。
2. 每次只调一只CT，小步交替调节，完整记录调整前后曲线。不能认为CT1只调左边、CT2只调右边；以两侧边界、29/33抑制共同判断，不只追31 MHz最大幅度。
3. 峰附近及两个−3.0103 dB边界改用**10 kHz或更细**步进，记录实际峰频与边界中点；双峰出现时记录峰间凹陷，不强行给一个单通带宽度。
4. 固定CT，重复拆接测量接口、移开工具、复测29/31/33和边界；再以一半源幅度复测，确认相对曲线不随幅度变化。记录变化范围作为重复性证据。
5. 若带宽或抑制异常，先检查测量总电容/端接、元件值与焊接，再单独改变线圈间距或方向；每次只变一项。带宽异常不能单独归因于互感，带宽合适也不能证明互感已消失。

**参考值必须与测点一致：**

| 条件 / 测点 | 边界中点 MHz | 连续−3 dB带宽 MHz | 29/33 MHz抑制 dB |
|---|---:|---:|---:|
| 用户指定S05-07参考，RF级输出 | 31.000 | 1.919 | 12.59 / 11.80 |
| S05-08器件模型原RF夹具，rf | 30.999 | 1.920 | 12.92 / 12.30 |
| 同一S05-08原始数组，LC port | 31.029 | 1.887 | 13.41 / 11.82 |
| 本轮独立953 Ω∥14 pF夹具，port（含两支1 MΩ） | 31.030 | 1.885 | 13.39 / 11.84 |

上表全是**仿真参考，不是实测**。1.85～1.95 MHz保留为工程带宽目标；独立port扫频要和port参考比较，不能要求每个测点都精确复现rf的1.919 MHz。采用 `D(f)=20log10[H(f)/H(31)]` 时负值表示抑制，表中的抑制取 `−D`。中心取两边界中点，不取31.42 MHz附近的单侧峰。校准后的电压传递 `H=Vport/V源开路` 不是S21。

使用[空白测量记录表](s05_10_measurement_20261030/加载扫频记录表.md)。若总误差不能分辨1.85～1.95 MHz的窗口，只记录结果与不确定度，不能写“通过”；仅接口总电容误差±1 pF就能使本模型带宽改变约45～52 kHz。
