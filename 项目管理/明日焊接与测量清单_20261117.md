## 2. 配电与上电顺序

独立板标出 +5V、GND、输入、输出和板号。每板入口放10 µF（正极接5 V）及100 nF；芯片/射频级附近就近安排100 nF，入口电容不代替长连线末端去耦。

先不插LM393，核对DIP座8脚到+5 V、4脚到GND，确认无短路，再断电插芯片。实验室电源先设5.0 V，单独LM393板以10 mA限流起步；现有独立R1振荡板沿用原图5 mA起步；新增缓冲单级可用10 mA，增益单级10 mA，三段载波级联以20 mA起步。这些是初调保护设定，不是合格电流上限。进入限流且电压跌落时先检查接线，不直接加大限流掩盖问题。

明天所有这里列出的发射模块用5 V实验电源，不把9 V电池直接接入其5 V供电点。示波器地夹只接共同GND；不能夹到晶体两端之一或晶体管非地节点来测差分电压。

## 3. LM393振荡/PWM小板——可以现在焊

只焊原基带模块的振荡和PWM部分，幅度电位器及调制级暂不连接。TI LM393P DIP-8脚位按芯片顶视图识别缺口/1脚：1=输出A，2=负输入A，3=正输入A，4=地，5=正输入B，6=负输入B，7=输出B，8=电源。两路输出为开集电极，必须装上拉。

| 连接 | 元件 |
|---|---|
| 8脚→+5 V，4脚→GND | 电源；100 nF就近跨8/4脚，10 µF放板入口 |
| +5 V→1脚(OSC) | 2.2 kΩ上拉 |
| +5 V→3脚(HYST) | 30 kΩ |
| 3脚→GND | 10 kΩ |
| 1脚→3脚 | 20 kΩ |
| 1脚→FSET→2脚(RAMP) | 22 kΩ固定＋可调电阻，串联 |
| 2脚→GND | 1 nF C0G；6脚直接接2脚 |
| +5 V→DUTY_TOP | 10 kΩ |
| DUTY_TOP→10 kΩ电位器→DUTY_BOT | 两个外端接TOP/BOT，滑端接5脚 |
| DUTY_BOT→GND | 4.7 kΩ |
| +5 V→7脚(PWM_RAW) | 2.2 kΩ上拉 |

现有料配值：30 kΩ=20 kΩ＋10 kΩ串联；每个2.2 kΩ=1 kΩ＋1 kΩ＋100 Ω＋100 Ω串联，均用台账已有件，低频板可这样实施。频率可调电阻用现有100 kΩ多圈微调，焊前调至约15.3 kΩ；滑端与其中一个外端并接，剩余外端与并接端作为两端。它替代的是原20 kΩ变阻器的调节范围，起始有效阻值不变，只用于本轮实验，须记录型号和最终阻值；不声称原标定表仍精确适用。占空比用现有10 kΩ微调，按万用表找出滑端，不猜物理中脚。

测试顺序：
1. 示波器10X、高阻输入，先看1脚方波和2脚充放电波形，调频率至20 kHz（周期50 µs）。
2. 看7脚方波，调10 kΩ电位器依次得到10%、30%、50%占空比。记录每档频率、高/低电平、Vpp、占空比及供电电流。
3. 每档留截图；改变占空比后复查频率。频率误差1%、占空比误差5个百分点是课程相关检查口径，不以肉眼“像方波”代替测量。
4. PWM_RAW接近电源幅度是正常的；此时未装20 kΩ幅度分压器，不叫最终V1，不宣称1–4 Vpp带载校准通过，也先不接调制管。

## 4. 载波缓冲与增益级——料齐，按级推进

这两级沿用现有C1/d05的连接。无源晶体参数测试夹具与有源晶体振荡板是两种东西：不要把测参数夹具当作31 MHz信号源。已有R1板先确认正常振荡，再连接下面两级。

onsemi 2N3904BU：厂家脚号1=E、2=B、3=C。按封装图确认观察方向；SPICE行的顺序C/B/E不是封装脚序。射频级不用长杜邦线、无焊面包板或大IC座连接；器件相邻、引线短、地回路紧贴信号回路。本文未给背面镜像孔位图，不照文字凭空套旧孔位。

### 4.1 射随缓冲QB

| 端点 | 接法 |
|---|---|
| QB集电极C | +5 V |
| QB基极B | 10 kΩ到+5 V，另10 kΩ到GND |
| 原振荡板发射极E→QB基极B | 串1 nF，取原E节点，不取2.2 pF弱耦合取样点 |
| QB发射极E→GND | 330 Ω |
| QB发射极E→BO输出 | 串1 nF |

先不连原振荡板，查QB直流：基极约2.3–2.5 V、发射极约1.6–1.9 V、集电极约5 V，仅为故障排查参考，不是精确验收线。再断电接入振荡板、重新上电，在BO测频率/幅度，并比较接入前后的起振和频率变化。BO经电容隔直，单独测试时可用两只1 kΩ串联成2 kΩ到地作已知负载；记录此负载，不把2 kΩ当课程要求。

### 4.2 共射增益QG

| 端点 | 接法 |
|---|---|
| QG基极B | 22 kΩ到+5 V，4.7 kΩ到GND |
| BO→QG基极B | 串10 nF；前级输出1 nF保留，勿擅自删掉 |
| QG发射极E→GND | 56 Ω，不并旁路电容 |
| QG集电极C→+5 V | 1 kΩ |
| QG集电极C→OUT | 串10 nF |
| OUT→GND | 两只1 kΩ串联成2 kΩ测试负载 |

先单独查QG直流：基极粗略0.75–0.9 V、发射极约0.1–0.25 V、集电极约1–3.5 V，受晶体管参数影响较大；若集电极贴近地或电源，先排查偏置和脚序。再接缓冲，测OUT的频率、Vpp、削顶/异常振荡、静态和工作电流。原仿真2 kΩ下约2 Vpp仅作对照，不保证实物相同。

前级BO的独立测试2 kΩ负载，在连接增益级时拆掉；最终2 kΩ负载只留在OUT，避免无意给缓冲加额外负载。示波器使用10X/高阻输入，探头电容仍会加载RF输出；不要同时再焊网表CLOADG=10 pF，否则可能重复计入探头负载。只测输出/取样点，不将普通探头直接跨晶体高阻节点。先截图再移动探头，保留相同测量条件用于比较。
