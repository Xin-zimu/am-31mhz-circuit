**线性误差定义**（引用时必须写明）：

```
归一化增益 = (Vout / Vin) / (Vout / Vin)@4Vpp
```

**物理特征**：输出方波高/低电平相对均值对称（4 Vpp 时 ±2.40 V，2 Vpp 时 ±1.19 V），直流偏置几乎不动，幅度缩小得比一半略多。与"解调器存在固定压降/开关阈值"的行为方向一致，**但本次未做机理定位，这只是与数据一致的描述**。

**−1.4435% 是否可接受取决于评分标准**，本报告只给数值与定义，不做合格判定。

## 4. 已完成的结论（接手者需要知道的边界）

### 4.1 GUI 冷启动失败：已定位，已找到可用配置

| 运行 | RELTOL/TRTOL | 结果 |
|---|---|---|
| 冷启动 20 µs GUI | 1e-4 / 1 | **失败**，停在 **225.797635 ns** |

**失败机制（已用数据证明，非推测）**：
- 停点锁定在 **7 个载波周期 = 225.806452 ns**（4 次运行、2 种积分方法、2 种步长上限，全部死在 ±11 ps 内）。
- 该处是**真实电路事件**：引擎在同一网表上跑 20 µs，全程只有 2 次步长骤降（启动时 0.08 ps、225.8 ns 时 1.21 ps），其余 60 个载波周期边界步长稳在 1008 ps。
- **决定性差异是步长控制的松紧**（同请求 1 ns 上限）：

| 指标 | GUI 1e-4（失败） | GUI 1e-3（通过） | 引擎 |
|---|---:|---:|---:|
| 中位步长 | 307.037 ps | 1000.000 ps | 1008.065 ps |
| 事件处最深步长 | **0.0116 ps** | 31.25 ps | 1.2095 ps |
| 达到上限比例 | 11.74% | 99.75% | 91.71% |

**必须保留的边界**：
- **1e-4 下的 GUI 冷启动仍然失败** —— 这是真实且**未消除**的求解器限制，不是已修复的缺陷。
- **1e-3 不是"放宽标准凑结果"**：它是 SPICE 默认值，也是引擎实际生效值，改成它使 GUI 与既有证据可比。
- **但 GUI 侧历史数据是混合容差的**（预充电 2 ms 跑在 1e-4 上）。**不得再笼统写"GUI 与引擎设置一致"。**
- 预充电 2 ms 与引擎同窗对比：幅度差约 0.068%、均值差约 0.866 mV，均远小于 0.1%，**不影响既有验收**。

证据：`gui_diagnosis_20261014\GUI失败原因诊断报告.md`、`gui_evidence_20261014\GUI冷启动20us成功报告.md`

## 5. 统一测量方法（必须沿用，保证可比）

全套脚本复用 `stage3_acceptance\measure_stage3.py` 的 `crossings` 交点函数，配套：

- **2 ns 均匀插值**网格
- **robust 幅度 = P98 − P2**
- **时间加权均值 = 梯形积分 / 窗口长度**（不是普通样本平均 —— 旧 `cold7ms_analysis.py` 用普通平均，其"6.5 ms 已稳定"结论已撤回）
- **末尾五个完整周期**，剔除不完整周期
- 0.1% 临时重复性筛查 = 周期均值跨度 / 平均幅度 < 0.1% **且** 幅度跨度 < 0.1% **且** 周期相对跨度 < 0.1%

**重要**：6.5 ms 之后判定"未通过 0.1%"的旧结论，应改述为**"当时仍在收敛"**，而不是"不收敛"。
