## 0. 为什么必须先问这件事

项目现在卡在一个**不能靠仿真、不能靠自证、也不能靠内部讨论解决**的点上。

已逐字核对最直接的课程原文 `电子线路实验评分标准-学生.docx`（73,513 字节，7 页，SHA-256 `657a5112…F94F23`），确认以下事实：

| 检查项 | 结果 |
|---|---|
| `Ω`（U+03A9 / U+2126）、`ohm`、`欧` | **0 次** |
| `负载`、`假负载`、`终端`、`匹配`、`阻抗`、`输出阻抗` | **0 次** |
| `2.0`、`包络`、`调制度`、`调制指数` | **0 次** |
| `50` | 11 次，10 次是占空比 `10~50%`/`50%`，1 次是 `±500kHz` 的一部分；**无一次表示电阻** |
| `探头`、`倍率`、`校准`、`MΩ` | **0 次** |

v3 行（表3 第3页，满分 4）的全部内容只有：

> 评分项目「调制波形 v3」｜性能指标要求「**指定调制波形**」｜评分标准「(1)波形：明显失真扣1。(2)载波中心频率漂移：大于1%扣1分；大于10%扣2分。(3)调频波频偏：大于±500kHz扣2分。」

而第5页《电子作品测试数据表》v3 栏的全部登记项是：「**失真：** **中心频率：** **调频波频偏：**」——没有幅度栏、没有负载栏、没有功率栏。

**关键的不对称**：同一份文件里，v1 的幅度写得极具体（「峰峰值1~4V可调」），v2 的幅度也写得极具体（「峰峰值不小于4V」，另有 4V/2V 两档扣分）。**课程设计者显然知道怎么写幅度门槛，v3 没写不是笔误，是没作要求。**

但"没要求"和"可以随便做"是两件事。原文对 v3 的幅度**完全空白**，因此连"把目标降到 0.4 Vpp 是否合规"都无法内部裁定。这就是必须问的原因。

**过去三个月里，项目一直把两件事当成课程要求，而它们都没有原文依据**：发射端必须向 50 Ω 交付 2.0/1.2 Vpp 包络。这两项现在已归为"历史工程测试条件"，但**归为工程条件不等于找到了正确的课程口径**——正确的口径只能由教师给出。

### Q1【测点】v3 调幅波形的正式测点在哪里？

- [ ] 功率放大器（或缓冲级）输出端

- [ ] 天线馈电点（接实际天线时）
- [ ] 其他：＿＿＿＿＿＿＿＿

> 说明：本项目内部把调制器输出叫 `tp3`。已核实冻结仿真网表中 `TP3` 只挂两个元件（POLY 受控源输出、一个理想压控电压源的输入端），**没有任何有限负载**，因此"TP3 上的电压"在物理上不代表任何带载能力。如果课程要看的其实是后级输出，我们现在测的位置就是错的。

原文只在报告环节要求"说明测试条件、测试仪器型号等"（属 1 分的写作扣分项），**未规定任何测量设置**。请确认：

| 示波器输入阻抗（1 MΩ / 50 Ω） | 是 / 否 | |
| 耦合方式（AC / DC） | 是 / 否 | |
| 带宽限制 | 是 / 否 | |

### Q6【接收端】v2 的正式判定条件

原文表3 写「峰峰值不小于4V」，第5页测试表写「峰峰值大于4V」，两处措辞不一致。请确认：

1. 以哪一处为准？ ≥4 V 还是 >4 V？
2. 该判定在哪个 v1 档位执行？（4 Vpp 标称点？）
3. v1 降为 50% 的线性测试中，v2 是否仍需满足 ≥4 V？——**按原文同时执行会自相矛盾**：v1=4 Vpp 时若 v2=4.8 Vpp，则 v1 降到 2 Vpp 时 v2 应为 2.4 Vpp，低于 4 V 门槛。请明确此处只考核比例、不考核绝对值。

### Q7【功耗】0.5 W 如何测量？

请确认测量边界：

1. 是否为电池端电压 × 平均电流（含稳压器自身损耗）？
2. 测量时天线是否连接？接实际天线还是假负载？
3. 在哪个 v1 档位、哪个占空比下测？
4. 取瞬态还是稳态？统计窗口多长？

> 说明：这是课程里**唯一一条既有数值门槛、又有明确扣分（>0.5 W 扣 4 分，>1 W 扣 8 分）**的发射端电气指标，因此它是最硬的约束。本项目当前预算 303.8 mW（含 8 mA 稳压器静态电流假设），余量约 39%，但这是预算不是实测。

## 2. 答复后如何处置（预先承诺，避免事后解释）

为避免"拿到答复再挑对自己有利的解释"，先写明各种答复对应的动作：

| 若教师答复 | 本项目将执行的动作 |
|---|---|
| **Q3 = 无幅度规定** | v3 验收清单缩减为"波形失真 + 载波中心频率漂移"两项，按表3 原文执行；**不再以任何幅度数字判 v3 合格与否**；驱动级必要性改由 Q6（v2≥4 Vpp @ 6 m）单独支撑 |
| **Q3 = 有幅度规定** | 若数值 ≠ 2.0/1.2 Vpp，则 AM-02.3 的历史判定按新数值重算（**需重新仿真**，届时另行立项，不在本轮四件事内）；若数值恰为 2.0/1.2 Vpp，则需按 Q2 的负载条件重跑——**同样需要新仿真** |
| **Q2 = 接实际天线** | AM-ALT.3 的匹配网络即为验收链路的一部分，P2 的天线实测从"阶段出口"升级为"验收前置条件"，优先级提到最高 |
| **Q2 = 接 50 Ω 假负载** | 50 Ω 从"历史工程条件"恢复为"课程条件"，但**必须同时拿到 Q3 的幅度数值**才有意义（只有负载没有幅度仍无法判定）；此时 AM-02.3 的 14.3 dB 缺口重新成为有效判据 |
| **Q4 = 规定 1 MΩ + ×10 探头** | 当前"用探头直接测天线节点会把谐振拉到 18.5 MHz"的警告降级；可改用直接电压测量 |
| **Q4 = 不规定** | 维持现有方案：10 Ω 电流取样 + 双通道差分，并在报告中声明测量条件 |
| **Q6 = 线性测试只考核比例** | 性能指标文件第 7 节 B1 冲突项关闭 |
| **Q8 = 有补充通知** | 全部既有"无原文依据"的结论需按补充通知重新核对，本轮结论可能部分失效 |

**在收到答复前，本项目不会**：把 v3 判为通过或失败、恢复 50 Ω 强制门槛、按 2.0/1.2 Vpp 做任何新设计、或据现有电路较易通过哪种口径而选择口径。
